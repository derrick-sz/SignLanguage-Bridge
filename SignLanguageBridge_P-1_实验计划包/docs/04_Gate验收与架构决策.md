# 04 · 阶段 Gate 与后端接入 ADR

## 一、Gate 定义

| Gate | 关联实验 | 必须交付 | 通过/阻塞准则 | 不通过时的处理 |
|---|---|---|---|---|
| G0 资产可追溯 | E00 | 代码 Git SHA、模型 checkpoint SHA256、数据快照、GPU/镜像、许可与输入协议 | 每个候选模型标记 READY/BLOCKED；两条既有路径至少可作 smoke，模型来源明晰 | 缺权重的模型可阻塞其分支，不得因 README 记载就视为已部署 |
| G1 输入与推理复现 | E01 | 50 条 Pilot 对照与异常样本报告 | 所有失败可解释；同配置输出差异可核验；无 silent preprocess mismatch | 不进入公平性能比较，先定位帧采样、裁剪、姿态、tokenizer/权重版本 |
| G2 同任务价值 | E02,E06 | BLEU/chrF、人评语义、误改和纠错、GT oracle 仅供分析 | 至少取得可比的 A 与 B 路径；保留 F vs E、G vs F；有新盲测后才宣称融合泛化增益 | 如无质量提升，默认保留单模型路线，不为复杂 LLM 调度增加成本 |
| G3 性能及流式能力 | E04,E05 | 设备详情、P50/P95、VRAM、串并行对照、Partial/Final、未来帧审计 | 模型路径无无法解决的 OOM；具备可复核的延迟测量；流式能力如实分类 | 若不能有效在线，保留整句离线识别分支并由在线方法处理增量输出 |
| G4 决策归档 | E00–E06 | ADR、实验链接、风险、回退方案、P0/P1 backlog | 所有方案选择均可追踪至 run_id；关键 BLOCKED 项有明确去向 | 只执行低耦合后端骨架；高风险集成延期 |

**不是所有 Gate 都必须在同一天达到“全部通过”。** 对模型权重受限或在线代码不兼容的分支，应记录 `BLOCKED`，选择可验证替代路线；但不可用未验证猜测代替正式结论。

## 三、优先判定路径

- **若 B/C 在统一翻译任务下优于 A**：优先把 SLRT 的句子翻译视为真实候选模型，不要只依赖 Gloss→LLM。
- **若 F 相比 E 无稳定增益**：多模型融合尚无足够收益证据，保持接口而不强制在生产推理中运行两路。
- **若 G 提高平均文本指标但显著增加严重语义误改**：默认拒绝启用 G 自动融合；保留人工审阅/拒判机制。
- **若并行峰值显存或 P95 远高于串行**：按实测选择串行/级联，而不是按算法概念强行并行。
- **若实时输出依赖未来帧**：不得宣称无等待实时翻译；披露窗口等待和真实首稳时延。
- **若 Jev 的错误接受率超过 Rule-only**：保持 Jev 为可选插件，而非核心决策器。

## 五、P-1 到 P0/P1 的交接

P0 可以接收：冻结的 EvidenceCandidate 合同、稳定的历史回放器、质量消融结果、实验指标导出方案。  
P1 可以接收：目标硬件性能曲线、模型 Worker 输入规范、跨模型一致的任务/状态定义、串行/并行/级联策略候选。  
P2 可以接收：已验证的在线分支、PTS 处理、Partial/Final 行为与时间等待明细。  
P3 需要新的 Libras 权重、数据协议和语言识别专门实验，不得仅依赖 CSL-Daily 推断。
