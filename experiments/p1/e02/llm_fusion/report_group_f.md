- 目的：验证 `docs/experiments/P-1/G2_IMPROVEMENT_ANALYSIS.md` 方向 1——把 LLM 从"事实仲裁者"降级为"语言组织者"：只给 SLRT Gloss 词列，不给 Uni-Sign 译文。

## 1. 结论摘要

**F < A（BLEU CI 不含 0）：当前 B0→LLM 造句未超过 A，需分析失败模式**

- F−A（BLEU-4）：Δ -12.6910 [-18.3408, -6.3451]（显著更差（CI 不含 0））
- F−B0（BLEU-4）：Δ 7.0725 [3.6445, 10.7000]（显著更好（CI 不含 0））
- B0−A（BLEU-4，基线对照）：Δ -18.6393 [-26.2983, -11.0978]
- F−A（char edit）：Δ -0.0943 [-0.1507, -0.0413]（显著更差（CI 不含 0））
- F−B0（char edit）：Δ 0.0459 [-0.0005, 0.0890]
- 逐样本 char edit（仅 43 条 F 成功样本）：F 高于 A 的 15 条、低于的 23 条、持平 5 条 —— 总体均值显著更低，但并非全面更差（见 §5 示例与 §6）。
- Gloss 词保留率（F 句中出现的 Gloss token 比例）：mean 0.8578，min 0.0000，max 1.0000，低于 1 的样本占比 0.1600（n=50）

## 2. 方法（与 C/D/E 的关键区别）

- **输入**：F 的 prompt 只含 SLRT Gloss 词列（本次按实验规格用空格分隔 token，即 `spaced_tokens`）；**不给** A/A2、槽位冲突、SLRT 分数、候选身份。
- **B0 基准**：评测里的 B0 是 E02 定义的无空格确定性 join（`"".join(tokens)`，无 G2T）；因此 F−B0 同时包含"分词 + 语言组织"两部分效应（§3.1 另给无空格对照）。
- **角色**：LLM 只做语言组织（把词列组成自然句），不做事实仲裁；因此与 C/D/E 的失败模式不同。
- **Prompt v3_f**：system 要求只输出一句中文、保留所有词汇意思、不得添加/删除/改变内容；user 模板含 `{gloss_text}` 与输出约束。
- **为何可能有效**：人评显示 Gloss 的动作槽位错误率 45.0% < A 的 57.5%，但 B0 流畅度仅 2.07/5；LLM 的强项正是把不通顺词列变通顺句。
- **固定条件**：同一 `pilot_50.csv` 50 条（与 v1/v2 真实运行同集）；temperature=0；max_tokens=2048；串行；未扩 1086。

## 4. 成本 / 稳定性

- 调用：50 次（成功 43，失败 7；重试 0 次）
- 延迟：P50 8.309 s，P95 14.093 s，mean 8.071 s
- tokens：prompt 8087 / completion 51167
- 失败原因：finish_reason={'length': 7}；error={'empty completion text (finish_reason=length; max_tokens=2048)': 7}
- 稳定性说明：7/50 次调用因 `finish_reason=length`（max_tokens=2048，推理模型耗尽预算）返回空文本；F 指标只在成功样本上计算（n_ok=43），失败样本未进入配对比较（该比较为 43 对）；失败样本未计入会让 F 的全量表现被高估（这些样本更难/更长），修复建议 max_tokens=4096（与 v2 E 组同因），但 4096 仍不保证 100% 成功。

## 6. 失败模式分析（自动统计 + 说明）

- **本次实测（F < A 的原因）**：F prompt 只给 Gloss 词列，LLM 确实把词列组成了通顺句，且平均保留 0.8578 的 Gloss token；但 Gloss 本身的错词（示例 4/5/8 的 `你们/不会/标准正确/书房子热行为` 等）被原样组织进句子，形成"通顺但事实仍错"；而 A（Uni-Sign）在多数样本上句法/虚词更完整，BLEU-4 高 12.69 分。即：**语言组织收益（相对 B0 +7.07 BLEU）不足以抵消 Gloss 不成句/错词带来的损失。**
- **指标口径提醒**：BLEU 对语义相近但措辞不同的句子惩罚很大（示例 6/7 的 F 语义接近 GT，但 n-gram 匹配低）；本结论是 BLEU/编辑距离口径，Round-2 人评需同时看语义正确性，不能只用 BLEU 判"F 没有价值"。
- **Gloss 词保留率** mean 0.8578，低于 1 的比例 0.1600：说明 LLM 是否会遗漏/改写 Gloss 词（规则 2 的违反程度）。
- 若 F < A：优先检查 ① Gloss 虚词/句法标记缺失导致 LLM 补错句法；② Gloss 词序不符合中文语序；③ 30% Gloss WER 本身错误词被原样保留/被 LLM 放大；④ 输出含解释/引号等格式噪声。
- 若 F > A：属于方向性发现候选，仍需新独立集/人评复核，不能据此单独推翻原 G2 FAIL（原结论针对"仲裁式融合"，本实验是不同路径）。
- 若两者接近：说明"语言组织"收益不足以抵消 Gloss 的不成句/错词；可转向方向 2（A 打补丁：保留 A 句法，只在 SLRT 高置信槽位替换）。
