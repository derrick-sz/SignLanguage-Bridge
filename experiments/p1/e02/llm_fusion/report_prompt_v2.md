   Gloss 证据与证据约束均**无显著字面增益**：如实记录为「当前 prompt 条件下 LLM 融合无质量收益证据」；不允许为了凑出正增益而继续在同一测试集上调 prompt。
3. 选择性级联（A unless rule trigger → E(v2)）：触发率 28.00%，BLEU 29.0890（Δ vs A -2.1418 [-5.2720, 0.4358]，CI 含 0（不显著）），估计成本较全调 E 节省 72.00% 调用。即使级联只调用少部分样本，其质量仍由 E 的质量决定——E 无增益时级联也不会有增益（成本问题与质量问题是分开的两问）。
4. **成本 vs 质量**：v2 每 50 条 C/D/E 的 total tokens 见 §5；若扩到 1086，按当前均值线性外推约 2736k tokens（估算，未实测）。当前证据不支持扩量。
5. **探索性边界**：50 条 retrospective_seen 子集、同一批样本上做了一次 v1→v2 prompt 迭代，**不是独立盲测、不能声称泛化提升**；最终 G2 结论需新独立集 + 人工评审（Round-1 包）。
6. 停止条件（预先声明）：若 v2 与 v1 均无 D−C/E−D 正增益且 C 仍劣于 A，则结论为「以当前 LLM prompt 方案做整句融合无质量收益」，应转向 B（G2T/SLT，仍 BLOCKED）或选择性/后处理路线，而不是继续调 prompt。
