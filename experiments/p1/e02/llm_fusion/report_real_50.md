## 0. 运行事故与修正（重要，先看）

- 首轮尝试 `g2a-wbproxy-50-20261026` 使用 `max_tokens=256`：73/150 次调用返回**空 completion**（HTTP 200，`finish_reason=length`，completion tokens 顶到 256，按组：{'C': 8, 'D': 34, 'E': 31}）。
- 诊断：`deepseek-v4.1-flash` 会先消耗 token 做内部推理，256 token 在较长 prompt（D/E）上不足以产出最终句；
  这不是代理故障，也不是指标问题。首轮结果因**选择性偏差**（只有短推理样本成功）不可用于质量结论，保留其 run 目录仅作事故证据，**不进入对比表**。
- 修正：本轮正式数据 `g2a-wbproxy-50-v2-20261026` 固定 `max_tokens=2048`（prompt 文本未变，仍是 `v1_zh`；run 级 override 记录在 manifest.decoding）。

## 6. 结论（探索性）

- **A → C（LLM 润色）：**ΔBLEU-4 = -4.5470 [-8.0167, -1.3843]（CI 不含 0，**指向负增益**）；Δchar edit = -0.0331 [-0.0676, -0.0016]（CI 不含 0，**指向负增益**）
- **C → D（Gloss 新增价值，核心判据）：**ΔBLEU-4 = -0.0355 [-4.9755, 5.3757]（CI 含 0（不显著））；Δchar edit = 0.0255 [-0.0052, 0.0591]（CI 含 0（不显著））
- **D → E（证据约束收益，核心判据）：**ΔBLEU-4 = 1.6232 [-3.0368, 6.8101]（CI 含 0（不显著））；Δchar edit = 0.0105 [-0.0327, 0.0486]（CI 含 0（不显著））
- **C → E（相对纯润色的总变化）：**ΔBLEU-4 = 2.0453 [-2.4896, 6.5297]（CI 含 0（不显著））；Δchar edit = 0.0403 [0.0019, 0.0821]（CI 不含 0，**指向正增益**）

解读（按 50 条证据，不作 G2 结论）：

1. **无条件 LLM 重写在本批数据上显著降低字面一致性**：C 相对 A 的 BLEU（-4.55）与字符编辑相似度（-0.033）CI 均不含 0；
   抽查示例可见模型会改写正确事实、补全证据外内容（如把「妈妈回房间工作」改写成无依据的「做这做那」）。
   这提示『全部重写』的融合方式风险高；若做融合，应先做**选择性改写/冲突时才升级**（与 E06 的 Rule-only 路由结论一致）。
2. **D − C 无显著字面增益**（BLEU CI 含 0；edit 点估计 +0.026、CI 边缘含 0）：50 条样本下 Gloss 证据的字面一致性收益不成立，只能说明方向不明确；与 E02 的 A/A2 差异同量级（编辑相似度差 ~0.005–0.03），需要更大样本/人评。
3. **E − D 方向为正但不显著**（BLEU +1.62、edit +0.011，CI 均含 0）；C → E 的字符编辑相似度CI 不含 0（+0.040 [0.0019, 0.0821]），提示『证据约束』比纯润色略好，但 BLEU 不确定。
4. **成本**：C/D/E 每 50 条分别 ~21k/38k/47k tokens、P50 2.0/3.8/3.9 s、P95 4.4/8.5/9.2 s；若扩到 1086 条，D/E 预计 ~80 万/100 万 tokens 级（按当前均值线性外推，未实测）。
5. **不能作为 G2 通过/否决依据**：50 条为 retrospective_seen 子集、无新独立集、无人工语义评审；
   且 prompt v1_zh 为首版、未做 prompt 迭代（模型内部推理消耗也会影响稳定性，3/150 次 2048-token 截断）。

建议下一步：

- **先改 prompt 再扩量**：C 只做最小必要修正（保留与证据一致的原句），D/E 明确「冲突才改」；新增 `v2_zh` 版本并重跑 50 条对比，而不是直接跑 1086。
- 结合 E06 的级联结论：优先评估「A 为默认、规则/分数触发才调 LLM」的选择性融合，而不是每句都调。
- 人工评审（Round-1 包）优先用于验证「LLM 改写是否引入新的关键事实错误」；自动 BLEU 不能替代语义判断。
- B（G2T/SLT）仍 BLOCKED；在拿到权重前，不建议把 LLM 后期融合作为主链路。

## 7. 边界与安全

1. 50 条为 E01 pilot 抽样（10 signer × 5），是 1086 的**子集**，不是新盲测；同 signer 内可能有同源样本。
2. 候选来源：A/A2/B0 为 E02 冻结历史预测；C/D/E 为本轮真实 LLM 生成（provider=wb-proxy, model=deepseek-v4.1-flash）。
3. **密钥安全**：仅运行时从 dsh credentials yaml 读入内存；未打印/未写入任何输出/JSONL/manifest/日志/本报告；manifest 只含 `credentials_ref` 引用。
4. GT 只在评测侧 join（`evaluate.py`）；LLM 输入 prompt 不含 GT（harness 的 gt_guard 与 prompt 隔离检查见 stub 自检 33/33）。
