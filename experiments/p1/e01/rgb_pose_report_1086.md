# Uni-Sign RGB+pose 接入与 1086 全集评测（E01）

- 状态：**FULL-1086 评测**（同一脚本/同一 pose archive/同一 trimmed 协议；非最终生产结论）
- 运行：`unisign-rgb-pose-1086-20261027`；GPU 单进程串行；device=cuda；dtype=bfloat16；num_beams=4
- 权重：RGB+pose `csl_daily_rgb_pose_slt.pth`（SHA256 `c2ba5d7ae32f3fa40f7c6807b5004042be81fca192abe7d8ed7182c0d13470f6`）
- 输入协议：pose=官方 released pose archive（与 A2 同源）；RGB=本地近似句段裁剪视频的左右手 crops (112×112)；帧映射用本地 RTMPose 对齐元数据 `best_start`。**不是官方 sentence-crop 视频**（本地未发布），这是本实验的主要偏差。

## 1. 结论摘要

- **RGB+pose vs pose-only（同实现控制）**：ΔBLEU 0.6631 [-0.3528, 1.3158]（不显著（CI 含 0））；论文方向为 +0.75 BLEU（26.36 vs 25.61）。本实验点估计 0.6631，与论文方向一致；1086 条样本的 CI 含 0（不显著；signer 聚类 CI 宽）。
- RGB+pose BLEU：26.3026；pose-only 控制：25.6395；A2（官方 pose 历史）：25.5846；A（视频历史）：24.8157。
- **与论文的对照（重要）**：RGB+pose BLEU 26.3026 vs 论文 26.36；pose-only 控制 25.6395 vs 论文 25.61；Δ 0.6631 vs 论文 +0.75 —— 绝对值与方向均高度吻合，说明输入协议（官方 pose + hand crop）可信；但 signer 聚类 95% CI 仍含 0，按预设判据仍未达显著（edit Δ 的 CI 不含 0，可作辅助证据）。
- **扩 1086 判定：Δ 的 CI 仍含 0 → 未达显著，维持 A2/pose-only 默认**（不因本实验改生产链路）。

## 2.2 覆盖率（产品视角：edit 相似度 ≥ 阈值的样本占比）

分母 = 1086 条样本；覆盖 = 该系统的 edit 相似度达到阈值（越高越好，1.0=完全一致）。

| 系统 / 并集 | edit ≥0.5 | ≥0.75 | ≥0.9 |
|---|---:|---:|---:|
| A（Uni-Sign video） | 35.2% | 11.9% | 2.7% |
| A2（官方 pose） | 36.5% | 12.2% | 3.2% |
| pose-only 控制 | 36.5% | 12.2% | 3.2% |
| RGB+pose | 38.8% | 12.1% | 3.2% |
| A ∪ A2 ∪ RGB+pose | 46.6% | 17.3% | 4.2% |
| A ∪ A2 ∪ pose控制 ∪ RGB+pose | 46.8% | 17.4% | 4.2% |

- **产品覆盖视角**：单模型 edit≥0.5 覆盖 A 35.2% / A2 36.5% / RGB+pose 38.8%；A∪A2∪RGB+pose 并集 46.6%（+10.1pp vs A2）；≥0.75 / ≥0.9 的并集增益较小（17.3% vs 12.2%；4.2% vs 3.2%），说明高精度覆盖仍受单模型上限限制，多模型并集主要改善“可用但不完全一致”的场景。

## 4. 失败 / 偏差记录

- RGB 视频缺失样本：0/1086；pose pkl 缺失：0/1086
- 主要偏差：本地 trimmed 视频是近似句段裁剪（RTMPose↔官方 keypoints 对齐），不是官方 Uni-Sign sentence-crop；官方 `sentence_frames-512x512.zip` 本地仍缺。帧映射偏移见 predictions 中的 `alignment_offset`（部分样本可达 -20 帧），因此 RGB 手部 crop 可能不是视频中精确对应帧 → 若 BLEU 低于论文方向，不能确定是模型/权重问题还是输入偏差。
- 帧映射偏移（start−best_start）：样本数 1086，min -170，median -1，max 14；偏移越大，RGB hand crop 与 pose 帧的对应越不可靠。
- 空输出样本数：0。
- 结构校验：RGB+pose 权重 1012 键与 pinned 模型定义完整匹配（missing/unexpected = 0），确认权重可加载；pose-only 控制在当前评测集上与 A2 历史值差 +0.0549 BLEU，说明本脚本 pose 分支实现与 A2 一致。

## 5. 能否推到 1086 / 建议

- 本报告是 1086 全集评测：若 §1 判定为"可评估进主链路"，下一步是 A2/pose-only/RGB+pose 三系统联合评测 + Round-2 人评；若判定为"未达显著/显著更差"，保持 A2/pose-only 默认，不接入 RGB+pose。
