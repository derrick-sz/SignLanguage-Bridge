# Godette v12 · 腿形与中性默认表情

这是在 v11 基础上的独立修订版，原版文件保留。本轮改善的是可见形体轮廓与默认表情，不是把原骨架重新缩腿，也不是完整动画成品。

## 文件

- `godette-v12-neutral.blend`：可编辑 Blender 文件，原骨架与绑定保留，默认口部采用中性姿态。
- `godette-v12-neutral.glb`：实际导出并重导入验证的项目模型，74 个蒙皮网格、227 骨、0 段嵌入动画。
- `neutral-lip-preset.json`：16 个唇骨的原始笑容与新中性姿态位置记录。只改变默认姿态，不改变 rest。
- `previews/`：真正 Blender 渲染的三视图、v11/v12 旧新对照、压力姿态和踝/鞋底修复对照。站姿三视图是独立审阅姿态；`glb-neutral-native-*` 是 GLB 保留原身体默认姿态后的回导效果。

## 实际改变

### 腿形与鞋

- 裆高与全部骨长不变。膝部横宽约96.5→90.8mm，小腿中段90.6→94.1mm，裤口91.2→80.3mm，形成平滑的膝、小腿与裤口过渡。
- 裤口下降13mm，减少细踝暴露。胯部z=.90m处前后厚度约199.9→190.4mm，缓和上衣下方鼓包。
- 鞋宽增加8%，鞋面高度增加16%，鞋长不变。原薄鞋边厚度约4.23→6.34mm；另外增加4.5mm封闭底板，与原鞋结构重叠装配，不能把两项厚度直接相加。
- 新造踝部皮肤上端朝小腿骨轴调整，并使用Foot到Leg_Lower的渐变蒙皮。修复抬脚时后裤腿露皮，不通过删除皮肤或加遮挡物处理。
- 新鞋底是实际封闭网格，修复原环状鞋壳仰视露出皮肤的问题。

### 默认表情

- 只修改16个Lip_*骨的默认平移，消除保存的强笑姿态。上唇位置归零，下唇7骨增加局部1.5mm闭合量；原旋转、缩放和其它脸骨默认状态保留。
- 原脸网格、UV、材质、蒙皮权重完全不变。原Object_7全部4815个顶点数据不变，原手部数据也不变。
- 原227骨的rest、父子层级及GLB inverse-bind matrices保持。不能把“rest不变”表述成“所有默认姿态不变”，16个唇骨默认位置确实改变了。

## 验证范围

- 独立六个状态：rest、原身体默认姿态、审阅站姿、左右抬髋35°/屈膝80°、双髋25°/屈膝50°。新裤自身及新裤与生成踝的穿面均为0。
- 三条压力姿态路径各21点，共63点，同样两类穿面均为0、坐标均有效。
- 两块新鞋底各128顶点、单连通闭壳、Euler=2、每条边恰好双面、绕向一致。1056条从脚底方向看向instep三角中心的射线全部先命中对应鞋底，没有皮肤首先露出。
- GLB与Blender实际回导核验通过。原IBM逐字节保留，只有声明的7件坐标、2个生成踝权重、新增2个底板及16个唇骨默认位置变化。实际回导最大世界坐标误差约1.47微米。
- 口型采用本版新的GLB摘要验证，不冒用v11摘要。生产源码副本中已对实际新GLB进行101档手动口型、复位和重复/倒跳检查；项目分支备份与完整回归结果由对应集成报告记录。自动口型仍未启用。

## 保留局限

- 原骨架小腿段较长，真实关节比例没有改变。当前仍有长小腿感、小腿略鼓和鞋后跟口偏尖的风格余项，不能以技术测试代替审美确认。
- 原Godette手部壳体与已有手指形变缺陷未修复。生成踝和instep之间原有皮肤拼接线仍在，鞋面/鞋边/底板为重叠装配；本版不是整个人体或整鞋一体无缝模型。
- 没有宣称所有服装与身体在任意动作下都无碰撞，也未完成手语语义验收、马尾动力学或自动口型。
- 保留原Godette头脸风格，未声称完全匹配参考设计图。约30万导出顶点，尚未制作移动端LOD。
