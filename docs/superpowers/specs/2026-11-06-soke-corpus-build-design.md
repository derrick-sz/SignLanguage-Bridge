# SOKE CSL-Daily 候选三维语料构建

用户已同意前一轮提出的少量代表样本完整验证，并明确要求“尝试下载并进行构建”。本次沿用现有动画工作树，下载官方原始包、核对整包目录覆盖，构建 20 段有本机原片的句级候选及可播放产物；不把候选当成语言审核通过的词典。

原始 ZIP 保留在 G:/Archive/Zenodo/SOKE/CSL-Daily-Fittings，记录字节和本地 SHA256，不全量展开逐帧文件。流式解析 ZIP64 中央目录，统计每个 sample ID 的帧号与标注覆盖；仅读取选中成员且核对 CRC。原始参数合并为每句一个数值 NPZ，禁止执行外部 pickle 的全局函数/构造器。三份索引也用静态操作码解释读取，嵌套 torch 内容作为惰性数据。

保留原始 root/body/hands/jaw/shape/expression/camera 参数。播放版本遵循 SOKE 的 upper-body 133D 表示：root 与 1..11 关节归零，12..21 保留；手关节加 neutral 模型的 hands_mean 一次；jaw 保留、眼部静止。原始形体/面部参数保存，不声称已映射到 Godette。复用现有绑定骨架、保守平滑、手腕 IK、角色导出；素材来源与模板 SHA 分别记录。

构建独立的研究候选 ZIP/manifest，沿用 MotionRegistry 与单独本地端口，保留原有 100 段演示与 8875 服务。所有新增条目的语言/动作审核为 unverified，未知许可不自动改写为商用或 MIT。完整序列结构、原片帧数、参数有限值、源文件身份、播放/导出分别核对，禁止将数值/浏览器通过当成语义验收。本机原片为未裁剪版本，帧数不等时保留参数序列并标记时间对齐未验证，不拉伸/截断原片；播放按原始论文的 native30FPS，发布参数时间戳尚未独立验证。
