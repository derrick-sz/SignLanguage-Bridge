# 自定义中文表达生成验证

持续目标新增优先项：用户关注库外中文表达能否产生三维手语。当前19,877段仅作整句检索，本阶段必须使用新输入实际生成动作，不能改字幕、替换相近整句、用目标真值姿态或测试句自身片段冒充生成。

沿用用户先前不训练新模型的条件。SOKE已核查的官方入口没有明确的训练后AMG权重下载；保留证据，不把DETO/mBART初始化资源当生成器。优先验证作者公开的SignSparK三流预训练模型（HF LionelLow/SignSparK，revision b907f25f9bb9f5a0adcaf131a23a155dc471d9a8），不训练。

## 选择

- 现有完整句检索：保留，无法满足新句生成。
- SOKE自回归生成：在完整AMG权重可验证前保留研究候选，不反向调用识别权重。
- SignSparK：已确认CSL训练与三流权重，约16.7GB下载。先单进程、batch1、逐流推理，避开上游Windows NCCL初始化；验证text-only全遮罩关键帧不泄漏GT，再接入官方train词段检索增强。

## 最小验收与边界

1. 来源、文件大小与作者HF LFS SHA逐项验证，可续传，不改现有识别环境、驱动和旧8876服务。
2. 独立环境复用已验证sm_120/cu128 Torch，所需版本以实际导入/算子为准；不以原训练GPU数量估计推理需求。
3. 生成脚本接收中文与明确采样长度/seed；text-only不得读取对应目标句姿态/长度/词段。keyframe_mask全false后网络中GT项确实为零。长度为显式生成参数，不伪装成已学时长预测。
4. 逐流加载、推理、释放，记录实际显存/耗时/数值稳定性，默认batch1，帧数有界。模型来自官方公开研究资源，输出保持未审核。
5. 核验6D旋转、左右手、手均值、归一化、面部与骨架协议，转换为当前55关节clip；保留原模型输出和处理摘要，不按相同维数猜测reshape。
6. 至少两个库外中文句实际生成有限、非静态动作，输入文本与输出来源绑定；一个生成动作在当前人物预览。单句能运行不等于表达含义正确。
7. 检索增强只取train词段；未知Gloss的fuzzy映射/丢弃必须阻止或明确报告，不能用上游默认静默映射。best_case不得作为自定义成功或泛化证据。
