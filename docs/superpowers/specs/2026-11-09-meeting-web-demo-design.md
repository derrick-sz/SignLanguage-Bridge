# 会议字幕 Web Demo

用户已在当前会话确认Web比赛Demo，并要求执行产品开发；此前屏幕框选方案已明确。本文件记录执行范围，不重新发起审批。

## 使用流程

`/communicate/`默认展示会议字幕：选择共享屏幕/窗口，在网页视频预览内拖框选中手语者，开始持续采集与分段识别。字幕按完成的片段追加，支持暂停、重新框选、编辑、导出及清空。另提供上传视频的真实回放路径，方便在比赛和不支持屏幕共享的浏览器演示。文字转手语及原面对面沟通页保留在`/communicate/assist.html`。

主视图左侧是视频与选区，右侧是当前识别结果和字幕记录；底部简洁操作条。默认不加载数字人和文字规划器，避免它们决定会议主流程是否可用。沿用蓝色品牌，会议画面用深蓝灰舞台、白色字幕区；中文系统字体，清晰字号层级，集中突出视频和文字。

## 工程边界

- 复用`/v1/communication/recognition(s)`；统一接口可返回`gloss_sequence`或`text`，不写死TFNet。另一会话负责识别模型选择、运行配置和适配器优化；本任务不覆盖其模型/启动配置修改。
- 只采集视频，不启用音频或摄像头。屏幕共享由用户主动选择来源；上传回放可在不共享桌面的情况下验证同一框选、编码和识别链。
- 选区使用视频真实尺寸与object-fit留白映射；限制合法面积，尺寸改变时暂停并要求重新确认。全画面按钮提供可键盘操作的替代路径。
- Canvas按选区渲染视频轨；每个MediaRecorder实例产生独立完整片段，保留源时间与片段身份。不把编码字节块当作独立视频。
- 分段支持按画面停顿和固定时长；明确画面活动不等于识别到手语。手动提交当前片段作为补充。静止画面不自动提交无穷空片段。
- 采集与推理解耦，有界队列、单请求执行。积压、丢弃、错误和空结果均显示，不静默制造字幕。
- 暂停、重选、换语种、结束共享和取消都递增来源世代，旧返回不能入字幕；已提交字幕保留。相同文字的不同片段可分别入记录。
- 原始模型结果、人工编辑和任务类型分别记录；词序列不改称自然语言翻译。只对实际完成的片段显示结果，不预填字幕。

## 验证

先验证坐标换算、编码与设备生命周期、字幕顺序和取消边界；再用真实上传视频在浏览器运行选区到模型到字幕链，并回归辅助页。实际屏幕来源选择需要用户在浏览器共享选择器中完成；未经允许不采集其他屏幕内容。记录未测范围，不把真实视频回放称为真实会议语义验收。
