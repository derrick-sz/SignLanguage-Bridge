# 主界面手语模型热切换

用户已于 2026-10-22 确认：先实现主界面的中国手语／巴西手语一键热切换，保持摄像头开启、后台加载、失败保留原模型，录制或识别时禁止切换。

## 范围与交互

- 在主界面视频／摄像头按钮旁显示“识别手语”选择框：中国手语、巴西手语。不提供自动判断语言选项。
- 当前选择始终表示实际激活的模型；加载时在旁边提示目标手语，加载成功后才更新选择、词表和模型标题。
- 默认从工作目录已有的中国 TFNet 和 Libras RF 模型目录取得两个候选；模型未配置时禁用对应候选并说明可在设置选择模型。支持传入候选路径，便于外部模型目录和验证。
- 保留设置中的自定义模型选择与恢复上个模型。自定义加载同一手语后，主界面候选更新为该实际模型目录；未知手语显示“其他手语模型”，不冒称中／巴手语。

## 加载与故障

- 复用 RecognitionSession 的后台 prepare／warmup／activate 事务，不增加自动语种分类器、第二套模型运行器或常驻双模型路由。
- 加载期间禁用切换，保留摄像头实例与实时预览；录制、识别、取消后仍未返回的原生任务期间均禁用切换。
- 成功切换清除当前结果和未完成动作，保留正式字幕历史；自动分段停止，用户可以重新开启。
- 失败时保留原模型、原选择和摄像头预览，提示切换失败与可恢复操作。不得把候选语言标成已激活。
- 取消加载后旧候选不得激活，选择恢复到实际模型。来源的真实错误仍按既有流程提示。
- 热切换表示应用运行中替换模型；加载期间暂停识别，不保证零等待或无缝连续推理。

## 验证

测试主界面选择、后台加载时 UI 心跳与预览、失败恢复、缺失模型、设置自定义／回退同步、取消与任务禁切，以及 980×720／1280×820 布局。
使用本地真实 RF 与 TFNet 模型及视频验证切换后输出类型、词表与结果同步；相机可用时测同一个相机实例上的切换与预览帧推进。测试与实际摄像头动作识别准确率分开报告。
