# SLRT 在线 CSLR 实施计划

**目标：** 新增独立 SLRT-CSL 后端，真实权重加载与真实 MP4 推理，并交付有界流会话、摄像头入口和明确验收边界。

**架构：** `slbridge/slrt/` 按资产、网络、预处理、姿态前端、解码、会话分工。复用来源及统一模型合同；不改变 RF、TFNet、Uni-Sign 的行为。

**依据：** 用户本次开发任务及 [架构兼容性分析](../../reports/slrt-architecture-compatibility-2026-10-24.md)。采用已授权的独立模块方案继续实施。

- [x] 阅读实际入口、依赖、Git 状态、官方网络和滑窗，记录架构与资源缺口。
- [x] 资产检查和严格加载：配置、词表、checkpoint、设备及独立推理网络；记录源码来源和校验和。
- [x] 官方 RGB/热力图预处理、HRNet/显式实验 RTMPose 前端；真实 MP4 输出和性能记录。官方 HRNet 资源缺失，端到端未验证。
- [x] 增量 Gloss 解码和有界流会话：partial/final、重复、EOS、队列、暂停重置释放；真实视频验证。`replay` 时间轴回放未单独存档；实时路径由摄像头试跑覆盖，词汇交付未通过。
- [x] 统一 Adapter 注册、独立 CLI/可选 Qt 面板、配置与依赖说明。
- [x] 针对性测试、既有回归、独立代码审查及交付报告；验收表明确真实验证、单元测试及 NOT_RUN。结果见[交付报告](../../reports/slrt-integration-2026-10-24.md)。

重点负向检查：词表错配、MediaPipe 输入、错视频的 pose 缓存、未来帧访问、A blank A、无检测到人体、EOF 未完成推理、暂停或源切换残留结果、采集快于推理时的有界性。
