# 可复现的训练示范与来源标识

用户授权按中巴竞赛场景持续自主优化。当前用户模仿数字人发生误识别，已有实时吞吐、词证据、本人核对闭环。本轮增加与当前模型语料一致的真人示范入口，同时如实保留问题回放，不改权重、FPS、识别规则或动画动作资产。

## 已有证据

当前Godette v14A人物承载SignSparK T2G规划与检索词动作组合。“我想睡觉”实际计划为我/想/睡觉，分别来自S000008(train)、S000054(dev)、S000384(train)，源片段9/5/13帧，加两段转接共39帧/30FPS，语言审核NOT_RUN。识别端是SLRT增量词+Uni-Sign句末，不构成动作生成器的逆模型。用户原录制仍缺，不能认定这是单例唯一原因。完整原计划保存在本轮产物目录，不混入模型评测。

## 实施

1. 本机配置显式启用4条固定媒体：介绍、校园、生活状态各1条来自已测train表达；第4条为已知误追加案例（加2秒静止尾部），明确标注问题回放。用原裁剪视频转H264、原FPS，不烧字幕，不收集新摄像头数据，不对外发布媒体。
2. 独立只读DemoCatalog，manifest限制大小/条数/字段，路径只能在manifest目录内，逐条SHA、train来源、视频大小/元数据约束；仅按固定ID提供FileResponse及只投影必要字段的目录API，支持视频Range，拒绝路径逃逸、未知ID、哈希失效，不允许请求指定文件路径。
3. scene_cli新增可选--demo-catalog，产品启动器读取profile.product.demo_catalog，完整相邻参数身份匹配并校验目录SHA。未启用时原入口不变；更新profile前先以旧配置StopProduct，经原启动器启动，识别服务保持不动。
4. 网页提供示范选择和清楚的来源标签：训练回放、已知问题回放、本地文件、摄像头、共享画面。标注显示在视频之外；播放示范不自动识别。开始识别从头回放，复用现有frame-only WS/自然EOF/核对流程。
5. caption保留本次本地来源标识，换源后旧记录仍可辨别。来源/示范标注不进入start/frame或LLM请求，目标文字不回填生成文本；strict协议及网络断言验证。媒体加载/换源/后台的epoch和intent保护保留。

## 验收

后端真实TestClient检查禁用、路径/大小/元数据/重复ID/哈希、文件读取与Range，启动器mock保护及实际目录变更拒绝；Node检查来源不进入WS、caption按会话绑定来源、示范重头识别和过期加载不影响新源。独立代码审查，4条实际HTTP媒体均走现有WS获得原始结果；浏览器从目录选择并识别、核对/换源，保存原始结果与截图。训练示范的可复现不称泛化、用户模仿、手语教学标准或真人语言审核通过。物理摄像头及双侧中巴任务仍需另验。

原视频和参考来源在artifacts/realtime-demo-catalog-20261111/。目录仅本机演示，模型训练语料与发布许可不在本轮扩展；官方数据来源：https://ustc-slr.github.io/datasets/2021_csl_daily/。

## 执行结果

本轮实现与本机部署已完成：后端32、Node29、隔离launcher17项通过；4条官方归属/标注及媒体SHA审计通过，HTTP/Range与真实WS请求4/4完成。3条正常示范与标注一致，问题输入仍保留原误追加。浏览器校园首词0.99s、问题回放1.18s（均含准备），无采样跳帧；原错误、重点核对、确认后换源及来源保留均实际可见。禁用配置/清单变化实际Start拒绝，恢复后两端PID不变，未重启识别服务。独立审查P2及quoted值补充问题均关闭。证据与未测边界见[执行报告](../../reports/realtime-demo-catalog-2026-11-11.md)。长期退化根因、跟练、摄像头和真人语言验收仍未解决，不因本计划工程完成而标记整体应用目标完成。
