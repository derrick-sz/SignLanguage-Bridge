# 数字人动作交叉核对与优化候选（2026-11-12）

## 范围及结论

对当前产品组合接口实际生成的“谢谢”和“我想睡觉”动作，使用同一 Godette v14A 角色、运行时重定向器及既有识别服务进行固定样本检查。构造了“我想睡觉”的隔离避碰轨迹候选，在抽样几何指标上改善，但回认仍无输出、最大偏移超过现行 0.06 限制、语言含义未经人工审核。**候选未接入产品，动作优化尚未验收。**

素材和预测边界见[先前同源对照](avatar-human-recognition-comparison-2026-11-12.md)。本次不将目标文本或参考标签送入识别接口，也不将人工提示、目标句或 LLM 改写当成预测。

“谢谢”的腕位置几何拟合好，但数字人回认仍为“骄傲”/“这个杯子十块钱。”；因此腕位置拟合或存在检测不能证明手形、掌向、脸部、图像模型泛化或语义正确。“我想睡觉”的组合动作仍含 dev 词片段，不能称为同一句真人视频配对。源动作与角色骨架差异、身体避让和视频域差异均需分开核对。

## 几何候选：研究性、不用于线上

在冻结的 39 帧“我想睡觉”上，以不加避碰的现有 IK 结果为基线，离线网格搜索手部平移；分别试验既有 0.06 上限和临时研究上限 0.08、相邻修正不超过 0.015，之后使用真实角色 FK/IK 对关键帧之间 1/8 帧的核心碰撞做局部迭代。该搜索专门针对本例输入，并非通用实时算法，不能用作独立泛化结果。

| 实际骨架复核 | 当前产品 | 精修隔离候选 |
| --- | ---: | ---: |
| 关键帧核心点采样命中次数 | 2 | 0 |
| 305 个插值时刻的核心点采样命中总数 | 61 | 0 |
| 相邻帧避碰修正最大变化 | 0.05826 | 0.01402 |
| 最大手部平移 | 0.06000 | **0.07952** |
| 指骨局部旋转最大差异 | 约 0 | 约 0 |

“命中次数”是头／躯干核心椭球内的关节和线段中点采样累计，不是独立碰撞事件；1/8 帧、核心椭球、关节和线段采样也不是完整网格、服饰或任意时间的碰撞认证。精修候选无 IK 夹限；较大的偏移可能改变触碰、身体相对位置或手语含义。

保留的失败候选：限制最大偏移 0.06、最大步进 0.015 的固定网格搜索得到 4 个关键帧点命中（原产品 2）；早期限制两端为零的版本得到 6 个。其平滑程度提高但碰撞更多，不能作为产品修复。只在关键帧评估的 0.08 候选虽为 0 关键帧命中，实际 FK/IK 在 305 个插值时刻仍有 13 次采样命中，进一步说明关键帧零命中不足以证明播放全过程安全。精修版本超出已有 0.06 约束，不能通过更改全局限制直接投产。

## 实际数字人视频与识别复测

使用产品 `MotionStage`、相同实际组合响应、相同画布尺度及固定 30 FPS 重采样；候选仅在隔离页替换播放轨迹，不修改产品文件。录制后以实时节奏将画面发送给 `/v1/communication/realtime`；LLM 关闭。与初始回放一样，画布以 0.8 秒静态开头、播放动作并保留约 1.2 秒静态尾部；这些是采集配置，不是摄像头验收。
