# 训练来源数字人动作的实时识别（2026-11-12）

## 结论

对当前项目可从本机训练动作库取出的 25 段**完整单词原生动作**，使用当前 Godette v14A 数字人渲染，再交给产品实时 SLRT＋Uni-Sign 链路。最终手语词与训练标注完整一致 **6/25（24%）**；实时句末中文与原句规范化完整一致 **8/25（32%）**。这是固定短动作、有限词汇的工程诊断，不是全部训练集、官方 benchmark、手语专家验收或摄像头模仿准确率。

两项指标不能相加：句末使用姿态输入及实时词/活动门控；**8/25 是整个实时句末链路的输出结果，不是独立 Uni-Sign 模型准确率**。25 条中 14 条没有最终词和句末输出，不能只在非空结果上算正确率。

| 指标 | 实测结果 |
| --- | ---: |
| 实时最终词序列完全匹配 | 6/25，24% |
| 实时最终词序列非空 | 11/25，44% |
| SLRT 词级 WER | 76%：25 个参考词，替换 5、删除 14、插入 0 |
| 句末中文完整匹配（NFKC、去空白） | 8/25，32% |
| 词和句子均完整匹配 | 6/25，24% |
| 句末中文非空 | 11/25，44% |
| 录制时序质量检查通过 | 25/25 |
| 实时接口请求、发送帧和处理帧 | 25/25 正常结束；2,331/2,331 帧，0 输入丢帧 |

完全匹配保留语义文字，不做同义改写；忽略全部标点后仍为 8/25。句末非空与词非空数量相同不意味着两个模型内部逐词串行。接口 `finished` 仅证明请求结束，不证明识别正确。

## 输入构建和身份

- 固定 `csl_iso.train` 中每个源视频**全部有效标注只有一个 Gloss**、且 CSL-Daily 官方 train 元数据对应词序列也只有同一 Gloss 的记录，输出完整 native LMDB take `[0, native_frame_count)`；不把句中切词、跨样本拼接或标注区间乘时间系数当作整句。预先枚举 26 源记录，构建后 25 条可读取，`S000444_P0000_T00` 在已核验 LMDB 中缺失，作为 `NOT_RUN` 而非正确或错误样本。25 条覆盖 8 个词、3 个源签者，按样本 ID 排序，全数计入，无按预测筛选。
- 数据集和动作库内容经项目既有 builder 验证：训练 LMDB SHA-256 `7dbc5dc932c6e34ea1d7d47976e8db8fb90ba4c2aff3eb05a6991c7008366222`，ISO 标注 SHA-256 `92cabbe0fcc97770abd491802be00cb35883a2237cabb7f0c5de847845355f2c`，每条 NPZ 和完整原始 blob 另有摘要。训练文本标注文件的 SHA 与先前训练集验证的冻结清单一致。
- 单动作使用产品 `WordLibrary` 源码、按 ID 精确指定已验证的素材，不运行文字到 Gloss 规划器、不将单词拼到其他样本；通过当前产品 `MotionStage` 和角色 Godette v14A 展示。这个批次只是测试识别器面对数字人画面的性能，**没有测试文字输入到规划器的完整端到端能力**。动作库本身标记 `product-demo`、`evaluation_eligible=false`，不是官方模型评测数据包；动画和手语语言质量均 `NOT_RUN`。
- 对每段测试页仅捕获数字人 canvas，无摄像头和屏幕内容；0.8 秒预留、以 30 FPS 播放完整原生动作并保留 1.2 秒结束静态，WebM 以时间戳重采样为 30 FPS、512×512 MP4V，再按时间节奏编码 JPEG90 送往 `/v1/communication/realtime`。25 段 WebM 均满足预先设置的录制质量检查：最长帧间隔 ≤0.15 秒、时长距预期 ≤0.25 秒；实际最大间隔约 0.043 秒、总共 2,331 帧。该检查不代表姿态精度或动画语义质量。
- 管线为 `slrt-pause-unisign-v1`；SLRT checkpoint SHA-256 `e9fdd3a66d9667e7685c2b1437c67b8cbc9e45d2562730f04c0226717b7cbd4d`，句末模型 `uni-sign-csl-daily-pose-only-182913ca`，LLM 关闭。素材准备和渲染须知道源词，但识别端的 WebSocket 请求只有图像及实时协议字段；参考标注在所有推理结束后才读取对比。没有提供提示词、目标文本或正确标签给识别器。

## 同源“谢谢”差异复核

此前一次 `S000003_P0000_T00` 数字人录制得到词“骄傲”、句子“这个杯子十块钱。”；本次同源动作视频无输出。已验证两次来自**相同动作参数和骨架**，两段 90 帧/30 FPS，但视频文件的画面不是逐像素相同：所有帧平均逐通道绝对差约 0.369/255。两段固定文件各交替重放 3 次，前者三次均“骄傲”及同一错误句，后者三次均无输出；每次 90 帧全部处理、无输入丢帧。

此实验说明不同录制产物对应不同且可复现的输出；不能仅凭它判定是某个像素、重采样、视频编码、采集时序或识别模型的哪一环造成差异。不得把这 6 次重放加进 25 条主分母。原始重复事件和像素比较见 `artifacts/avatar-train-eval-20261112/repeat/`。

## 产物及边界

25 段录制、转码视频、冻结输入与参考、实时事件和统计在 `artifacts/avatar-train-eval-20261112/`；`prepare.py`、`server.py`、`batch.mjs`、`replay.py`、`evaluate.py`、`evaluate_repeat.py` 可复核流程。推理请求失败或帧计数不一致时脚本停止，不静默删样。本轮未改产品代码或模型权重，未测真人摄像头、数字人动作专家审核、长句、全部训练语料或模型在新签者上的泛化。
