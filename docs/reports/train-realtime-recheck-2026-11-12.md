# 当前服务训练样本实时回放复核（2026-11-12）

## 结果

在当前运行的产品实时接口上重新回放此前冻结的 30 条 CSL-Daily 官方训练划分视频（30 种表达、8 位签者），并复测黑帧、静止人物两项控制。该批是按作者姿态区间截取、最长 200 帧的既见训练样本，不是完整训练集、未见测试集或真人摄像头模仿评测。

| 指标 | 本轮实测 |
| --- | --- |
| 训练样本请求完成 | 30/30 |
| 句末中文非空 | 30/30 |
| 句末完整文本与标注经 NFKC、去空白后完全一致 | 29/30（96.67%） |
| 最终 SLRT Gloss 序列与词标注完全一致 | 11/30（36.67%） |
| SLRT 词级 WER | 18.90%（254 个参考词，替换 17、删除 27、插入 4） |
| 两个静止/无动作控制 | 黑帧和静止人物均无词、无句 |
| 训练视频送达与处理 | 6,113/6,113 帧；服务报告输入丢帧 0 |

词序列逐句完整一致率与词级 WER、句末整句一致率含义不同，不能将 96.67% 当成 SLRT 词准确率。WER 是编辑错误数除以参考词数，不是每词正确概率；中文标注完整匹配也不等于对不同说法的语义评分。两项控制不是所有无效动作的全面拒答验证。

## 样本示例

- `S001622_P0005_T00`：参考“今天发钱，我们去饭店吃火锅。”，句末中文与标注一致；参考词序列为“今天 发 钱 我们 饭店 去 吃 火锅”，SLRT 输出中多了一个“酒”。
- `S000068_P0000_T00`：参考“小猫在桌子下面。”，实时输出“小猫在桌子下面。没钱,我出去玩。”。正确句后误追加第二句，因此整段计为不匹配，不只统计正确前缀。最终词为“桌子 下 小 猫 坐 没有”，而参考为“桌子 下 小 猫 在”。

本轮所有 30 条原始句末文本和最终词序列均与 2026-11-10 的固定样本实时回放结果一致；这是相同样本、同链路的复测，不能算作新的独立样本。此前同批视频的完整视频上传结果是历史实测 30/30，本轮**没有重跑完整视频上传**。

## 输入与协议

- 基于 `artifacts/train-application-validation-v2/manifest.json` 冻结的 30 条正例与 2 控制，推理前逐个验证输入文件 SHA-256；原数据源、裁剪区间和选择规则见[训练应用验证报告](training-application-validation.md)。参考词和文本直到所有推理完成后才读取用于评估。
- 每个样本使用同一 512×512 MP4V、原 FPS、JPEG 质量 90，按实时时间向 `ws://127.0.0.1:8879/v1/communication/realtime` 发送，末尾重复最后一帧 1.2 秒并正常 finish。两次指标口径一致；非物理摄像头采集。
- 管线 `slrt-pause-unisign-v1`，SLRT 权重 SHA-256 `e9fdd3a66d9667e7685c2b1437c67b8cbc9e45d2562730f04c0226717b7cbd4d`，实时翻译 `uni-sign-csl-daily-pose-only-182913ca`，8765 模型接口显示 Uni-Sign 版本 `73bea87a9603f719b4f4a481a3a1a5ed24e7e5f7b81afd14ef498c40469c1a6c`。LLM 关闭。
- 训练视频首个 partial 词从回放采集起点算 P50 0.736 秒、P95 1.056 秒，n=30；该指标不包含准备时间、真人拍摄差异或摄像头采集延迟，不能作为完整体验时延承诺。

## 证据和限制

本轮逐条参考与输出表（本地产物：`artifacts/train-realtime-recheck-20261112/eval/comparison.csv`）、汇总（本地产物：`artifacts/train-realtime-recheck-20261112/eval/summary.json`）、`outputs/` 原始事件和 `manifest.json`、`run.py`、`evaluate.py` 均保留在独立产物目录。评估前检查 32/32 正常结束、发送帧等于处理帧且输入丢帧为零；正例帧数和控制帧数分开。

这批结果支持在已有语料覆盖的固定表达中继续做应用验证；30 条短句不足以推算全部 18,401 条训练标注的效果。数字人重定向动作、用户模仿、新签者、完整真实摄像头流和更长句子未由本轮覆盖；此前“我想睡觉”数字人回认无输出的结果不因该训练视频回放而改变。
