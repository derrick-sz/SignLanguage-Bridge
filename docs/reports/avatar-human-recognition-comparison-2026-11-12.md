# 同源真人与数字人动作识别对照（2026-11-12）

## 结论及范围

对 CSL-Daily 训练样本 `S000003_P0000_T00` 的一次工程对照中，真人源视频识别为“谢谢”；项目数字人播放同样本动作后的画布识别为“骄傲”，句末译为“这个杯子十块钱。”，与样本标注不一致。两次请求均完成且输入帧全部处理。该例证实当前端到端系统对这段数字人画面不能可靠回认；不能单独判定动画动作语义错误，也不能计算整体准确率或推断任意动作、真人模仿的效果。

## 数据和方法

- 数据集源标注：句子“谢谢！”、词“谢谢”；源文件 `G:/Archive/Zenodo/csl-daliy/S000003_P0000_T00.mp4`，SHA-256 `32456d14569b1610701e26095daa5163cf6dc0a9a58b5aec5d68a70397bb95bb`。这是训练集样本，原视频 123 帧、30 FPS。
- 当前运行服务的文字转手语组合接口对“谢谢”返回 `exact_native_utterance`，30 帧、30 FPS，来源记录为同一 ID 的完整 0–30 动作。动作素材与原视频同 ID，但动作 30 帧不等于视频 123 帧逐帧对齐；产品工作区 `docs/reports/thanks-native-gesture-2026-11-09.md` 的素材核验提供来源背景。
- 使用产品当前 `MotionStage`、当前角色/展示配置和组合接口实际返回的动作，在临时 loopback 验证页单独录制 512 CSS 像素画布，不含文字、摄像头或桌面；WebM 实际 640×640、90 帧，时间戳从 0 到 2.970 秒，相邻最大间隔 0.039 秒。画布包含约 0.8 秒开始静态、1 秒动作、约 1.2 秒结束静态。帧间像素差确认并非全程静帧；动画经过重定向与平滑，画面不等同原视频。
- 真人源视频全长缩放至 512×512，并追加 1.2 秒末帧；数字人画布以时间戳重采样至 30 FPS、缩放至 512×512，不再补尾。两者起止静止段、时长与输入域不同，因此这不是严格逐帧配对试验。
- 两段均按视频时间通过产品 `/v1/communication/realtime` WebSocket 实时节奏回放，JPEG 质量 90、LLM 辅助关闭。预测请求不包含目标文字、参考标签或示范标注；识别结束后才将结果与独立标签比较。测试并非真实摄像头或网页采样链路验收。
- 管线 `slrt-pause-unisign-v1`；SLRT `slrt-emnlp24-csl-daily`，checkpoint SHA-256 `e9fdd3a66d9667e7685c2b1437c67b8cbc9e45d2562730f04c0226717b7cbd4d`；句末 Uni-Sign `uni-sign-csl-daily-pose-only-182913ca`。服务的词事件和句事件原样保留。

## “我想睡觉”组合动作附测

同一服务对“我想睡觉”组合生成 39 帧、30 FPS 的动作，依次取自“我”“想”“睡觉”三个词素材，并非同一数据集原句；其中“想”来自 dev，另外两段来自 train。服务标记 `experimental=true`、`human_approved=false`，语言、动作和组合审核均为 `NOT_RUN`。使用与上面相同的产品渲染器和仅录画布方法录制，再以同一实时接口回放：录制 99 帧、时间戳跨度 3.272 秒，最大帧间隔 0.039 秒；99 帧全部处理、输入丢帧 0、23 个窗口推理，正常结束，但没有词事件或句末译文。帧间像素差确认录像有运动。此结果不证明源素材本身错误，也不能代替用户先前摄像头模仿“绿色”的复现。

附测的组成接口数据、画布视频、输入清单及原始事件在 `artifacts/avatar-sleep-compare-20261112/`。识别请求仅含画面和实时协议数据，不含目标句或词标签；目标句仅用于生成数字人动作及事后比较。

## 证据与未完成项

- 原始输出、输入清单、组成接口完整结果、采集视频及脚本保存在 `artifacts/avatar-human-compare-20261112/`，其中 `human-output.json` 和 `avatar-output.json` 包含未修改的事件流，`avatar.webm` 为实际画布采集，`avatar-512.mp4` 为识别输入。
- “我想睡觉”附测是跨素材组合，不是同原句真人视频配对。尚未比较多样本、不同数字人视角/尺寸、不同签者、摄像头模仿、识别中间关节点与源动作偏差；亦未由合格手语人员审核动作含义。
- 现象可能与数字人/真人的视觉域差异、重定向、姿态/手形损失、切段和模型泛化有关，但此对照不能区分根因。建议先核验数字人回放中的人体/双手关键点及动作阶段，再以相同时间窗口、画面比例和多个同源样本重复比较；不要将 LLM 改写视为识别或手语语义证据。
