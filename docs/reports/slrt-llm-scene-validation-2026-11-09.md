# SLRT + LLM 小闭环实测

日期：2026-11-09（Asia/Taipei）。用户选择完整小闭环：词识别、LLM整理及事实变化、实时交付均执行验证。**结论：增量词能交付；本次受约束的LLM整理没有证明质量净收益，延迟和语义风险均不支持直接作为自动实时中文字幕主链路。** 生产8765/8879的Uni-Sign路由未更改。

## 输入、模型与边界

- 预先固定三个日常主题，各10条，共30条CSL-Daily test视频、28种参考句，覆盖数据集内10名签者；排除旧Pilot-50。全部来自已见过的`retrospective_seen_1086`目录，**不是新拍摄、新签者泛化或独立盲测**。
- 输入按原FPS派生为512×512 MP4V，保留原帧数，并绑定源视频与派生视频SHA256；两种识别路径使用同一派生视频。这是当前capture分辨率下的实验，不是官方HRNet输入复现。
- SLRT：938键严格加载、2001类（含blank）、`cslr_best.ckpt` SHA256 `e9fdd3a66d9667e7685c2b1437c67b8cbc9e45d2562730f04c0226717b7cbd4d`；CUDA、RTMPose实验CUDA前端；16帧窗、stride=1、vote=7、queue=32，使用当前帧缓存v2实现。没有修改模型/识别源码或算法参数。
- LLM：现有wb-proxy端点，返回模型名`deepseek-v4.1-flash`；temperature=0、max_tokens=4096、超时35秒、无重试。仅发送实际预测词与统一的日常交流范围，不发送参考答案、预期练习句、Uni-Sign译文或GT派生分数。密钥只在内存解析，产物仅保留凭据引用。
- 固定6条正例做原FPS回放（每主题前两条），另加黑帧和单帧重复的静止人物控制。SLRT事件与LLM异步整理真实同时运行；最多一个在途请求和一个最新待办，旧版本完成后丢弃。`final`只是解码提交状态，不是人工确认或语义正确。

协议：[实验协议](../experiments/slrt-llm-scenes-2026-11-09.md)。运行目录：本轮产物（本地产物：`artifacts/slrt-llm-scene-validation-20261109-v1`）。

## 3. 按原FPS回放的真实交付

| 指标 | 6条正例结果 |
|---|---|
| 自然EOF完成，无运行异常／无截止取消 | 6/6 |
| 视频采集结束前交付至少一个解码final词 | **6/6** |
| 首个final词墙钟（预加载后的会话起点计） | P50 **1.54秒**、P95 **2.37秒** |
| 出现队列丢帧的会话 | **5/6** |
| 总采集／推理接收／队列丢弃 | 608 / 592 / **16帧** |
| 与同一视频完整文件识别的词序列完全一致 | **1/6** |
| 同6条完整文件／原速回放WER | **37.50% / 50.00%**（参考32词） |
| 视频结束前已发布中文草稿 | **0/6** |
| 最后词版本对应的LLM结果 | **4条draft、2条insufficient** |
| 最终有效draft在采集结束后的额外等待 | P50 **6.29秒**、P95 **11.33秒**，仅4条有draft |

首个final词不是整句正确字幕；6条样本的P95只是本轮描述值，不能当产品SLA。采集、事件和LLM完成时间统一到同一`perf_counter`原点；原始session时间另保留。最新词版本拒答时，历史草稿不算最终有效输出：例如`S003692_P0001_T00`曾发布“去工作。”，最终词列增加后返回信息不足，不能把旧草稿重新计为最终译文。

这说明当前实现能交付增量词，但掉帧/窗口中断伴随词列损失，LLM随后还需等待并可能解释错误。此次没有做无丢帧对照来单独归因全部质量下降，也没有做吞吐调参后重选更好的结果。

黑帧与静止人物两项控制，各90帧，在完整文件和回放中均无词、无实际LLM调用。它们只证明这两个输入的行为，不能外推为全面未知动作／超场景拒识能力。

## 后续优先级

1. 稳定SLRT词流的排队与帧连续性，以原FPS持续交付和词损失为准；降低采样率或修改窗口属于另一协议，须重新对照。
2. 收紧到明确的意图与人物/否定/时间/数字/动作槽位，使用真实上下文做澄清；LLM保持可撤回草稿。不要用练习句或参考答案补成“识别正确”。
3. 再验证低延迟的语言整理方式；当前推理端点的长尾和4096-token空输出不适合直接挡在字幕前。
4. 用新录制、目标签者和真实相机做下一阶段验证，并由真人核对语义。当前日常主题粗筛不能替代正式场景定义。
