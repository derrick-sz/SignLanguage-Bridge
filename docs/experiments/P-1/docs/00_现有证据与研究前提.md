## 0.2 P-1 的数据标识和隔离规则

- `sample_id`：原始 `sample` 字段，例如 `S000020_P0004_T00`。不要重新分配 ID。
- `signer_id`：从 `sample_id` 的中段读取，例如 `P0004`。跨人验证按 signer 分组，不得将同一 signer 的相似视频随机分散到训练/盲测中。
- `source_dataset` 固定为 `CSL-Daily`；当前 1086 个样本的 `analysis_scope` 标注 `retrospective_seen_1086`。
- `fps`：旧表**未给出每视频真实 fps**，严禁凭帧数生成毫秒时间戳。只有实际容器/FFprobe 检查后才记录 FPS/PTS；对可变帧率以逐帧 PTS 为准。
- 记录 `raw_video_sha256`、`pose_sha256`、`crop_sha256`，便于区分输入视频与衍生姿态。
- 训练、阈值选择、prompt 修改等探索性工作可以使用已分析的 1086 条，但是不能再将它们宣称为完全未见的最终测试集。必须另外收集或划分**未被探索过程暴露**的评估数据，尽量覆盖新 signer/新环境。

### GT 隔离（最重要）

| 组件 | 可以访问 | 不能访问 |
|---|---|---|
| 视觉模型推理 Worker | 视频、其预处理、模型配置、时间戳 | GT sentence、GT Gloss、样本 WER |
| Jev / LLM | 两模型预测、公开规则、已校准且验证过的可靠性信息 | GT、历史错误标签、由 GT 计算的 edit similarity |
| 离线 EvalWorker | 预测、版本、GT、人工评审结果 | 不应将 EvalWorker 的结果反馈到当前 run 的推理输入 |
| 人工评审 | 按评审协议揭示候选及参考答案 | 不应修改原始模型预测 |

建议原始 GT 与预测日志在数据库中分表、分读权限，最小原型也至少分目录，`runs/.../predictions.jsonl` 不放 GT。

## 0.3 Pilot 50 选择说明

从已分析过的数据中选取 50 条用于环境和模块诊断。方法：10 名 signer 各取 5 条，在每个 signer 内优先覆盖以下历史诊断类目，并以帧长排序增强跨度：

1. `GLOSS_STRONG_UNI_WEAK`：Uni-Sign 字符相似度 < 0.5，SLRT WER ≤ 0.2。
2. `UNI_STRONG_GLOSS_WEAK`：Uni-Sign 相似度 ≥ 0.75，SLRT WER ≥ 0.4。
3. `BOTH_WEAK`：Uni-Sign 相似度 < 0.5，SLRT WER ≥ 0.5。
4. `BOTH_STRONG`：Uni-Sign 相似度 ≥ 0.75，SLRT WER ≤ 0.2。
5. `MIXED`：剩余情况（用于普通样本的稳健性检查）。

上述类别的划分借助了 GT 指标，因此 pilot **只用于复现、性能探针、故障定位，不用于评估不可见集泛化能力**。详细 `data/pilot_50_exploratory.csv` 不含 GT sentence / GT Gloss，可作为模型输入清单；敏感分层信息不得注入模型推理。

## 0.4 人工评审/测试反泄漏策略

- 单独锁定评审样本和评分指南后，才生成 LLM/Jev 输入。
- 每项融合试验使用固定 prompt 版本、温度、模型版本，并记录所有参数。
- 开发时可使用既有 1086 进行探索，若需要上线/论文证明，最终须使用独立新视频盲测。
- 人工评审候选顺序随机、尽可能隐藏模型名称；对核心语义双评审并记录分歧。
- 原始视频、识别文本及译文的许可、肖像和数据使用协议需要登记。

## 0.5 源数据使用限制

CSL-Daily 本身可能有研究与访问要求。交付包仅携带已经由用户上传的派生指标/预测以及计划模板，**不包含原始 CSL-Daily 视频或任何预训练权重**。后续下载和部署前需要独立核对数据与模型的使用权限、协议和许可证。
