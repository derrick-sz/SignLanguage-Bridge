# Leave-One-Signer-Out 效果敏感性分析（S2 vs A2，2026-10-27）

> **命名说明（按用户要求）**：本实验是**效果敏感性分析**，**不是跨 signer 泛化验证**。模型权重固定、1086 条测试样本已被反复分析，
> 每次排除一个 signer 不会产生真正的独立新 signer 测试集。它只回答"已观测到的提升是否依赖个别 signer"。
>
> 数据：test 1086（`retrospective_seen_1086`）；A2 = stage1 官方 pose；S2 = stage2 pose 子集（纯 pose 架构）。
> 指标口径：canonical p1-v1（字符分隔 + sacrebleu 13a）；edit = 字符级编辑相似度。

## 3. 影响最大分析

- 贡献最大的是 **P0000**：排除后 Δedit 从 +0.0146 降到 +0.0109（−0.0038），ΔBLEU 从 +0.714 降到 +0.196（−0.518）。
- 但 P0000 占 test 的 **34.4%（374/1086）**——这是**样本量效应**，不是"只靠它"：它的单位样本增益（+0.0218）与 P0007（+0.0251）、P0008（+0.0218）同量级。
- 唯一退化 signer 是 **P0006**（n=55，Δedit −0.0088，ΔBLEU −1.600），需在后续监控中单列。

## 5. 对"S2 能否成为默认"的意义

| 问题 | 回答 |
|---|---|
| 提升是否只靠一两个 signer？ | **否**：edit 在 9/10 signer 上为正，留一后 10/10 仍为正 |
| 是否存在群体退化？ | 仅 P0006（5.1% 样本）退化，其余 9 个 signer edit 均改善 |
| BLEU 的增益是否稳健？ | 较弱：只 5/10 signer 为正，聚类 CI 含 0 |
| 能否替代真实未见 signer 评测？ | **不能**：权重固定、样本已反复分析，本分析只证明"不依赖个别 signer" |

**结论**：S2 的提升在 signer 维度上是**弥散且一致**的（尤其 edit），不存在"一两个 signer 拉动全局"的问题；但 BLEU 增益集中、统计不显著，且 P0006 需单独观察。这支持"**dev/test 默认启用 S2**"，**不足以**支持"生产默认切换"——与用户决定一致。
