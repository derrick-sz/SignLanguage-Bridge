# Round-3 评审协议（Rubric v2 · 双人独立盲评）

> 立项：2026-10-27。目的：用修订量表**双人独立盲评**确认两件事——
> ①S2 相对 A2 是否**降低关键事实错误风险**；②是否提升**可支持可靠沟通**率（与产品就绪直接相关）。
> 评审包生成器：[round3_tools/](../../../experiments/p1/e06/round3_tools/)；实际包在 `experiments/p1/e06/human_review/round3/`（EVAL-ONLY，不入库）。

## 1. 为什么要有 v2：Round-2 的口径冲突

Round-2（90 行）实测交叉表暴露了 v1 量表的缺陷：

| 交叉 | 行数 | 占比 |
|---|---:|---:|
| 严重错误=是 **且** 可用于交流=是 | 58/90 | **64.4%** |
| 评分=0（完全错误）却评"可交流" | 7/12 | 58% |
| 流畅度=5 却仍有严重错误 | 33/55 | 60% |

根因：v1 的「可用于交流」被当作"能猜到大意"用；「严重语义错误」几乎等价于"评分≤2"。两者不独立，导致
93.3% 的"可交流率"无法作为产品就绪证据。

## 2. v2 的四处修改

| 项 | v1 | **v2** |
|---|---|---|
| 交流可用性 | 单列「可用于交流」 | **拆两列**：「可理解部分信息」（能猜到大意）与「**可支持可靠沟通**」（含义准确到可直接使用） |
| 严重语义错误 | 隐含"整体很差" | **正交定义**：六槽位（人物/否定/数字/时间/动作/对象）任一被改变且会导致误解 → 是；与评分独立（评分 3 也可能是） |
| 判定建议 | 无 | 「可支持可靠沟通=是」建议仅当 **评分≥3 且 严重语义错误=否** |
| 评审方式 | 单评审（Round-1/2 为 AI 辅助 + 用户确认） | **双人独立盲评**，互不参考；分歧行按仲裁清单处理 |

## 3. 评审包结构

| 文件 | 内容 |
|---|---|
| `round3_reviewer_A_template.xlsx` / `_B_template.xlsx` | 两位评审各自的填写表（同一批题、同一盲序，**各自独立**填） |
| `round3_review_template.csv` | 同内容 CSV（脚本/替代填写） |
| `blind_map_EVAL_ONLY.csv` | `review_id ↔ sample_id/candidate_id/model`（**评审时不得查看**） |
| `sampling_manifest.json` | 抽样规则、种子、哈希、量表明细 |
| `README.md` | 面向评审人的三步走说明 |

- 规模：**30 样本 × 3 候选（A 视频 / A2 stage1 pose / S2 stage2 子集）= 90 行**。
- 抽样：signer 分层、每签者 3 条、无偏随机（seed `20261030`，与 Round-2 **同一批样本**，便于同题对照）。
- 盲序：全局打乱（seed `20261032`，**Round-3 新序**，不沿用 Round-2 行序）。

## 5. 判定标准（写在 stats 里，先定后看）

| 判断 | 阈值 |
|---|---|
| **关键事实错误风险** | S2 的 `严重语义错误` 率 **≤** A2，且 `gained > lost`（A2 未标记→S2 标记 视为 gained） |
| **可靠沟通** | S2 的 `可支持可靠沟通=是` 率 **≥** A2，且 `lost`（A2 是→S2 否）接近 0 |
| **可理解性不退化** | 同上，作为辅助 |
| **评审一致性** | 两人 `评分` 的 ±1 一致率、二次加权 kappa；`严重语义错误` 的 kappa；**仲裁行占比（协议口径 = 任意评分差异或严重错误不同）**；另报实质分歧（评分差≥2 或严重错误不同） |

**口径说明**：`paired_*` 的 gain/lost 采用**保守合并口径**——双评审中**任一人**判「是」即认为该候选在该列达标（宁可多算风险，不漏风险）；
而 `per_candidate` 是按**每位评审分别**聚合的（`per_candidate[评审人][候选]`），两者不可混读。

## 6. 结果如何用于决策

- 若 v2 下 S2 的 `reliable_communication` 不低于 A2、`severe_fact_error` 不高于 A2 且 `lost` 很少 → 支持 S2 进入"生产候选下一阶段"（仍需新 signer 数据）；
- 若 v2 下 S2 的优势消失（v1 的 +0.30 主要来自"可理解"而非"可靠沟通"）→ 说明 Round-2 的增益是"更通顺/更好懂"，而非"更准确"，此时**不应**推进生产切换；
- 无论结果如何，**双评审一致性**（kappa）决定这份证据的权重：kappa 低（<0.2）时结论只能作方向性参考。

## 7. 边界

1. 数据仍是 `retrospective_seen_1086` 子集，**不是新盲测**；本协议不解决泛化验证。
2. 双人评审需要真实人力；AI 辅助填写只能作为预填，不能替代双人独立评审。
3. 参考译文只供判定语义，**不得回灌模型/提示词**；`blind_map` 属 EVAL-ONLY。
4. 30 样本 × 0–4 粗量表对 +0.2~0.3 量级的效应功效有限；若要点估计稳定但 CI 过宽，可扩到 60 样本（同协议、扩抽样）。
