**回答的问题**：目标场景里哪些语义类别识别弱？这些弱是「训练数据不够」还是「模型/训练方法不行」？也就是：**先扩数据，还是先训模型？**

## 0. 一句话结论

- 12 类语义里只有 **1 类**达到正式的弱类别阈值（S2 edit < 0.40 且 n_test ≥ 30）；其中只有 1 类在长度校正后仍低于同句长预期（残差贴着 -0.02 的边界值，量级很小）。
- 类别之间的差距其实很小：12 类的 S2 edit 全部落在 **0.384–0.501** 区间，以整体基准 0.4358 为中心，**没有出现某类塌陷**。
- **类别级数据不缺**：train 命中量 1,609–10,806 条（最少的是「亲属称谓」，训练占比 8.7%），全部高于「数据不足」阈值 300；train/test 类别占比比 0.81–1.19，**测试集没有系统性地多考训练集稀缺的语义**。
- **词表级也没有缺口**：测试集 gloss 覆盖率 100.0%、字符覆盖率 99.7%，含训练集未见 gloss 的测试样本 **0 条**。
- 因此瓶颈判断见 §9：**优先训模型 / 改训练方法**；按语义类别平铺扩数据不会命中真实缺口（数据扩容若要做，应针对词项长尾与句式多样性）。

- **错误类型**：字符级 Levenshtein 回溯统计 替换(S)/删除(D)/插入(I)，并按「每 100 参考字符」归一（`p1-v1` 的 `_edit_ops`）。D 近似「漏译」（参考有、输出缺），I 近似「多译」（输出多出内容），S 近似「替换」（位置对、字错）。

## 6. 证据：训练量到底能不能解释表现？

### 6.1 词项级（每个关键词）「train 频次 → test 平均 edit」

- 可用词项 135 个（test ≥5 次且 train >0）。`log10(n_train)` 与平均 edit 的 **Spearman ρ = -0.025**、Pearson r = -0.077。

| 词项频次五分位 | train 频次区间 | 词项数 | 覆盖 test 样本（可重叠） | 平均 edit | 该组词项所在句均长 |
|---|---|---:|---:|---:|---:|
| Q1 | 31–99 | 27 | 190 | 0.463 | 16.77 |
| Q2 | 101–156 | 27 | 238 | 0.480 | 16.49 |
| Q3 | 171–260 | 27 | 354 | 0.448 | 18.38 |
| Q4 | 261–466 | 27 | 507 | 0.448 | 16.49 |
| Q5 | 500–5844 | 27 | 2143 | 0.448 | 17.23 |

- 最稀有五分位（Q1，平均 0.463）与最高频五分位（Q5，平均 0.448）只差 +0.015：**词项频次几乎不预测该类词项的成败**。

- **长度控制后**（只留所在句均长 ≤15 字的词项，n=26）：低频半（13 项，句均长 13.29）平均 edit **0.524**、高频半（13 项，句均长 14.20）平均 edit **0.496**，差 **+0.028**。即句长固定后仍是低频略好，说明这个反向关系不是句长造成的；结论仍是不存在「训练频次越高 → 表现越好」的正关系。

### 6.2 类别级（每个语义类别）「n_train → edit」

- 12 个类别上，`log10(n_train)` 与类别平均 edit 的 **Spearman ρ = -0.434**、Pearson r = -0.278，没有出现「训练量越大越好」的正关系。注意只有 12 个类别点，|ρ|=0.43 在这个样本量下并不统计显著，但它至少**没有提供任何「补样本量就能改善」的支持**——而这正是「按类别扩数据」路线需要的证据。
- 换成**长度校正残差**再做一次同样的相关：ρ = **-0.392**（残差 = 该类 edit 减去同句长分箱的全体均值）。即便把句长效应扣掉，「训练量 → 表现」依旧不是正关系，所以这个结论不是句长混杂造出来的。

- 词表设计事实：12 类共 326 个词表项，其中 **24 项在 train 与 test 都是 0 命中**（CSL-Daily 语料本身不用这些词，例如部分姻亲/方言称谓），另有 302 项实际生效。这些 0 命中项是词表冗余，不是数据缺口——补它们的数据也不会改变测试分数。

- 解读：**「这句话的字面搭配在训练集里出现过没有」是目前找到的最强非句长预测因子**（同句长下高低覆盖组差 0.23–0.27 edit）。注意要点有两层：
  1. 它衡量的是**字面新颖度**，不是语义类别——所以「按语义类别补数据」不会改变它；
  2. 它与「模型靠字面记忆」一致（训练集上 99.5% 完全匹配、测试集 1.7%），因此**单纯加大同分布数据只会追加更多可记忆的字面形式**，收益递减；真正要补的是**未见搭配与长句**这类绝对量稀缺的区间。
- **稳健性（排除标点差异伪影）**：测试参考与训练文本的标点写法不同（全角 vs 半角），但全部未见二元组里只有 **5.3%** 涉及标点；只统计汉字二元组时平均覆盖率 73.8%（全二元组口径 77.9%），量级一致。→「字面新颖度」信号不是标点造成的伪影。

## 9. 总体判断：优先扩数据，还是优先训模型？

**结论：优先训模型 / 改训练方法。** 但要说清两件事——「扩数据」这条路线里只有**一种定向形式**有证据支持（补长句与未见字面搭配），而「按语义类别补数据」在本数据上找不到缺口。

证据链（每条都可回查 §2–§8 的数字）：

1. **类别级数据不缺**（§2）：12 类 train 命中量 1,609–10,806 条，最少「亲属称谓」也有 8.7% 的训练占比，远高于「数据不足」阈值 300；train/test 类别占比比 0.81–1.19，测试集没有集中考核训练集稀缺的语义。→ 按任务给定的判定规则（n_train<300 才算数据不足），**没有一个类别落入「数据不足」**。
2. **类别级「训练量 → 表现」没有正关系**（§6.2）：Spearman ρ = -0.434。如果瓶颈是「量」，这里最该出现强正相关。
3. **词项级频次同样没有「见得多就更好」**（§6.1）：Spearman ρ = -0.025；Q1（最稀有，平均 0.463）与 Q5（最高频，平均 0.448）差 +0.015，长度控制后仍不成立。词项级数据缺口（train<30 次但 test≥3 次）只驱动弱类别里个位数样本。
4. **符号层零缺口，但字面搭配层有明显缺口**（§7）：测试集 gloss 覆盖率 100.0%、含未见 gloss 的样本 0 条；然而字符二元组覆盖率只有 77.9%，且它在**同句长条件下**仍与 edit 强正相关（高低覆盖组差 0.23–0.27）。→ 模型不是「没见过某个手语符号」，而是**「没见过这种字面搭配」时明显退化**，这是泛化不足的直接证据。
5. **错误类型是「替换＋漏译」而非「多译」**（§4）：替换 60.5%、删除 26.3%、插入 13.2%，且输出普遍短于参考 → 生成端覆盖不足，属训练目标/解码问题。
6. **类别差异基本被句长吃掉**（§5/§8）：句长与 edit 的 r = -0.254，长度校正后连唯一的正式弱类别残差也只有 -0.02 量级 → 语义类别本身不是误差的结构化来源。
7. **与既有泛化结论一致**：A2（Uni-Sign 官方 pose）在训练子集上 99.5% 完全匹配、在 test 上只有 1.66%（[TRAIN_VS_TEST_GAP](TRAIN_VS_TEST_GAP.md)）——容量够、拟合够，缺的是泛化。一个能在训练集上逐字复现的模型，对「字面新颖度」高度敏感是必然的；此时**同分布扩数据主要是在增加可记忆的表面形式**，边际收益低于改训练方法。

**两条路线各自正确的形式**：

- **训模型（首选）**：在训练目标/正则化/增广/表征层面提升组合泛化，目标是让 edit 不再如此依赖「字面搭配是否见过」。这是唯一能整体平移 12 类的杠杆——实测 12 类相对 A2 的 Δedit 全部落在 -0.0104…+0.0218，说明模型层面的改动是系统性起作用。
- **扩数据（次选，必须定向）**：只补 (a) 长句（>25 字，n=51、edit 0.309）；(b) bigram 覆盖率低四分位的字面新颖句式；(c) train<30 次的长尾词项。这三处的共性是**绝对样本量小**，与语义类别无关。
- **明确不要做**：按「弱类别」立项补数据。唯一过阈值的「因果/条件」长度校正残差仅 -0.02，且它与「否定/数字/比较」在多标签下高度重叠，专项补数据既定位不准、收益上限也很低。

旁证：S2 相对 A2 的增益是**普遍性**的（只有 2 类为负），且 A2/S2 的类别间排序几乎一致——说明主要差距是**模型与训练方法层面的系统性差距**，而不是被某个语义类的数据缺口卡住。

按类的判定：

- **偏「数据不足 / 优先扩数据」**：无（没有弱类别同时满足「训练量低于阈值」或「词项级缺口 ≥25%」）。
- **偏「模型/训练方法」**：因果/条件（n_train 2,419，edit 0.384）

## 10. 局限

- 类别为多标签关键词匹配，非互斥；一个句子可同时落在多类，类别指标之间不可相加。
- 词表由人工按 CSL-Daily 日常域语料设计：24 个词表项在 train/test 都是 0 命中（语料不用这些词），另有极低频邻域词可能未被收录，故类别召回不完整。
- 错误类型为字符级 Levenshtein 回溯（替换/删除/插入），与「语义级漏译/多译」只近似对应。
- A2 与 S2 共用同一 1086 测试集与同一参考，Δedit 为配对比较；两者不是同一次运行的超参扫描。
- 长度校正使用全体测试样本的长度分箱均值，只能消掉分箱级长度效应，不是连续变量的回归校正。
- n_train 统计的是「含该类关键词的训练句子数」，不等于「该类语义的训练覆盖量」。
- 类别级相关系数只有 12 个点，符号可读但不宜当显著性结论；词项级 135 个点更可靠。
- bigram 覆盖率衡量「字面搭配是否在训练集出现过」，它会同时反映句式常见度与难度，不能单独解释为「数据缺口」的因果证据。
- 本报告只做评测侧统计，不涉及任何训练；GT 原文不进入报告，表格内只出现计数与指标。
