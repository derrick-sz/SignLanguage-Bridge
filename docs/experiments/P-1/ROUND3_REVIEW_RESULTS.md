# Round-3 人评最终结果（Rubric v2 · 双人独立盲评，2026-10-27）

> 评审表：`experiments/p1/e06/human_review/round3/round3_reviewer_A_filled.xlsx`（评审人 `Codex-AI-A`）、`round3_reviewer_B_filled.xlsx`（评审人 `B`），均 90/90 完整。
> 样本：30 样本 × 3 候选（A 视频 / A2 stage1 pose / S2 stage2 子集），与 Round-2 **同一批样本**、**新盲序**（seed 20261032）。
> 统计：`make_round3_package.py stats --reviewer-a ... --reviewer-b ...` → `round3_stats.json`。

## 0. 一句话结论

**Rubric v2 下 S2 相对 A2 只剩很小的、不显著的聚合优势（平均分 +0.18，CI 含 0），且逐例严重事实错误反而多了 1 例；Round-2 的 +0.30 优势是 v1「可用于交流」口径造成的假象。** 两位评审一致性高（二次加权 kappa 0.871），因此"没有大效应"这一结论本身是可信的。

## 1. 双评审一致性（本轮的证据强度基础）

| 指标 | 值 |
|---|---|
| 评分 完全一致 / ±1 内 | 64.4% / **100%** |
| **评分 二次加权 kappa** | **0.871**（高度一致） |
| 严重语义错误 agreement / kappa | 91.1% / **0.712** |
| 可支持可靠沟通 agreement / kappa | 91.1% / **0.712** |
| 需仲裁（协议口径：任意评分差异或严重错误不同） | **36/90（40.0%）** |
| 其中实质分歧（评分差≥2 或严重错误不同） | 8/90（8.9%）；评分类 32 行、严重错误类 8 行（有重叠） |

协议口径下需仲裁 **36 行（40%）**——远高于我原先报告的 8 行：原实现只筛「评分差≥2 或严重错误不同」，与 README「任意评分差异都仲裁」不一致，已修正（工具同时输出 `arbitration_rows`（协议口径）与 `material_disagreement_rows`（实质分歧））。
实质分歧 8 行的模式很一致：**评审 A 判「严重事实错误=是」而 B 判「否」占 7/8**（A 更严），评分差均 ≤1。
→ 结论不变（一致性 kappa 0.871/0.712 仍成立），但"分歧很少（8.9%）"的说法应改为"**实质分歧 8.9%，但按协议仍有 40% 的行需要仲裁/确认**"。

## 4. 与 v1（Round-2）的对照 —— 结论反转的原因

| 指标 | v1（Round-2，AI 辅助单评） | **v2（Round-3，双人独立）** |
|---|---|---|
| S2−A2 平均分 | +0.300 | **+0.183（CI 含 0）** |
| 「可用于交流」（v1） | 93.3% vs 86.7%（+6.6pp） | — |
| **「可支持可靠沟通」（v2）** | — | **23.3% vs 20.0%（+3.3pp，净 +1 例）** |
| 严重事实错误 | 73.3% vs 80.0% | **83.3% vs 86.7%（逐例净 −1）** |

**解释**：v1 的「可用于交流」测到的是"更通顺、更容易猜到大意"；换成"含义准确到可直接使用"后，S2 的优势从 +6.6pp 收缩到 +3.3pp，且逐例严重错误不再更少。**Round-2 的口径张力（58/90 行"严重错误且判可交流"）在此得到直接验证。**

## 5. 关键产品数字：可靠沟通率 ~20%

| 候选 | 可支持可靠沟通（双评审） | 严重事实错误 |
|---|---:|---:|
| A（视频） | 20.0%（A:13.3 / B:26.7） | 80.0% |
| A2（stage1 pose） | 16.7%（A:13.3 / B:20.0） | 83.3% |
| S2（stage2 pose 子集） | 20.0%（A:20.0 / B:20.0） | 80.0% |

即：**当前三个候选里，只有约 1/5 的句子达到"含义可直接用于交流"**；4/5 需要人工修正。这与 P-1.5（字面新颖度是主要瓶颈）和训练集 99.5% vs 测试 1.7% 的泛化落差一致。

## 6. 决策

| 决策 | 结论 |
|---|---|
| 生产默认（prod） | **保持 A2**（用户选项 B 得到进一步支持）：v2 下 S2 无显著优势 |
| dev/test 默认 S2 | **可保留**（便于对比实验），但文档需注明"v2 未显示显著质量优势" |
| 产品形态 | **辅助 + 人工确认**（可靠沟通 ~20%，不能做自动字幕） |
| 是否继续投入文本级/权重级优化 | **否**：三个候选的差距在噪声内；下一步资金应投向训练侧（组合泛化）或新数据 |
| 放行条件（生产切 S2） | 不成立——v2 下无显著优势，不满足"纠对 > 改错 + 严重错误不增"的双条件 |

## 7. 局限

1. n=30、0–4 量表：+0.18 的效应量在噪声内；若要点估计稳定需扩到 60–90 样本。
2. 评审 A 为 AI 辅助（`Codex-AI-A`），评审 B 为真人代号 `B`；A 是否完全人工未在表中区分——引用时应写"一位 AI 辅助 + 一位人工"。
3. 「可支持可靠沟通」两位评审绝对值差异较大（13–27%），该列仍需更明确的锚例（建议 v3 给出 3–5 个分档示例句）。
4. 数据仍为 `retrospective_seen_1086` 子集，非新盲测。
