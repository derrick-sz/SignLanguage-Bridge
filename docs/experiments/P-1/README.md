## 核心纪律

- **不可把这 1086 条视为全新、未被研究者观察过的最终盲测集**。本包中的小样本选择同样属于探索性用途；独立结论需要未见的新样本/新的签署者（signer）。
- 所有前端推理、Jev/LLM 调度、融合 prompt **不可接收 GT sentence、GT Gloss、逐样本 WER 或按 GT 计算的字符相似度**；这些字段仅供离线评价。
- 不允许把不同任务的 WER 与 BLEU 值直接比较大小，也不允许把未校准的 score 当作准确概率。
- 不重训、不改写官方权重作为 P-1 默认任务；新增的模型训练必须有独立记录和原因。
- 不上传带授权限制的视频/关键点/权重到公共仓库；不要在日志中存密钥。
- 任何官方声称的 online 模型都要按“是否需要未来帧、是否产生 Partial、是否复用状态、实测首稳时间”独立验证。
- 标记 **PASS / FAIL / BLOCKED / NOT_APPLICABLE**，不可把尚未运行的实验写成已通过。
