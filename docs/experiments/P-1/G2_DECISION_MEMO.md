# G2 决策备忘录：双模型 + LLM 融合是否进入后端主链路

> 决策人：Lead（本备忘录由 Lead 依据实测证据撰写；独立模型评审尝试失败，见 §7）
> 日期：2026-10-27 · 状态：**ACCEPTED（不进入主链路）**
> 对应：RQ3（Gloss→Text/SLT 与双模型融合能否提高译文质量）、RQ7（Jev/LLM 能否纠错而不覆盖正确答案）；Gate G2；ADR-P1-010
> 证据边界：**50 条 Pilot-50 探索批，`retrospective_seen`，不是最终盲测**；两组 prompt（v1、v2）、单端点（wb-proxy）单模型（deepseek-v4.1-flash）、无人评。

## 1. 决策问题与验收三问

用户（2026-10-26 批复）要求以三问验收 G2：

1. **翻译质量是否确实提高？**（canonical BLEU-4/chrF + 按 signer 聚类 bootstrap，禁止凭个案）
2. **是否引入新的关键事实错误？**（人物/否定/数字/时间/动作/对象六槽位盲评，统计纠对/改错）
3. **增加的计算成本是否值得？**（LLM 调用数/tokens/P50-P95 时延 vs 单模型基线）

判据（预先约定）：`D vs C` 验证 Gloss 新增价值；`E vs D` 验证证据约束。若 D/C/E 不能稳定优于 A，则不启用融合。

## 2. 证据汇总（全部来自实测 run，可复算）

### 2.1 分组

| 组 | 方案 | 说明 |
|---|---|---|
| A | Uni-Sign 原句（基准） | 不调 LLM |
| C | Uni-Sign → LLM（润色对照） | v1 开放改写；v2 最小必要修正 |
| D | Uni-Sign + SLRT Gloss → LLM | v1/v2 同 prompt 族 |

| B | SLRT → G2T/SLT | **BLOCKED**（CSL-Daily G2T/SLT 权重未发布）——B0 仅为确定性 join 基线，不得据此否定 SLRT |

### 2.2 质量（canonical p1-v1；50 条 Pilot-50；GT = 上游 `test_tmp_refs.txt` 参考）

| 组 | v1 BLEU-4 | v2 BLEU-4 | v2 chrF | v2 edit | v2 n |
|---|---:|---:|---:|---:|---:|
| A | **31.2308** | **31.2308** | 27.1849 | 0.4831 | 50 |
| C | 26.6838 | 28.9518 | 24.8547 | 0.4858 | 50 |
| D | 26.9450 | 28.5872 | 24.2824 | 0.4831 | 50 |
| E | 28.6302 | 29.1880 | 24.8223 | 0.4930 | 45（5 次长推理截断） |

配对差（后者−前者，signer 聚类 bootstrap 1000 iters，seed=20261026）：

| 比较 | v1 ΔBLEU [95% CI] | v2 ΔBLEU [95% CI] | v2 Δedit [95% CI] |
|---|---|---|---|
| C − A | **−4.55 [−8.02, −1.38]** | **−2.28 [−4.04, −0.70]** | +0.0027 [−0.0045, +0.0124] |
| D − C（Gloss 价值） | −0.04 [−4.98, +5.38] | −0.365 [−2.95, +1.91] | −0.0027 [−0.035, +0.030] |
| E − D（约束价值） | +1.62 [−3.04, +6.81] | −0.416 [−2.43, +1.47] | +0.0054 [−0.016, +0.031] |
| E − C | +2.05（BLEU n.s.）；edit **+0.040 [+0.0019, +0.0821]** | −1.62 [−4.53, +0.91] | −0.0074 [−0.030, +0.015] |

**解读**：v2 prompt 显著收窄了 LLM 的伤害（C 的 −4.55 → −2.28），但**仍未追平 A**；`D−C` 与 `E−D` 在两版 prompt 下都**不显著**；v1 中 E 相对 C 的 edit 优势在 v2 中消失（说明 v1 的"优势"部分来自 prompt 差异而非稳定的证据增益）。字符编辑相似度整体中性（CI 均含 0）。

### 2.3 选择性级联（默认 A，规则触发才调 E；offline 重放，不新增调用）

触发信号 = E06 RuleJudge 槽位冲突（数字/否定/人物/疑问）；触发率 **28%**（14/50）。

| 策略 | 调用率 | BLEU-4 | ΔBLEU vs A [CI] | 估算 tokens | 估算 LLM 时延 |
|---|---:|---:|---|---:|---:|
| always A | 0% | **31.2308** | 0（基准） | 0 | 0 |
| A unless rule → E | 28% | 29.089 | **−2.14 [−5.27, +0.44]** | 15,154 | 71 s（50 条合计） |
| always E | 100% | 24.6668 | **−6.56 [−9.70, −2.85]** | 54,120 | 253 s |

**解读**：级联把成本降到 always-E 的 28%（相对省 72%），但质量仍**低于纯 A**（ΔBLEU −2.14，CI 含 0 但点估计为负；Δedit −0.0201 [−0.0505, +0.0066]）。即"选择性调用"能省钱，但**没有省出质量**。

### 2.4 成本（v2 prompt，实测）

- tokens：C 25,696 / D 38,887 / E 48,708；合计 **113,291**；按触发级联估算 ~15k。
- 延迟（HTTP 端到端，串行）：C P50 2.04 s / P95 5.02 s；D P50 3.01 s / P95 9.10 s；E P50 4.48 s / P95 9.49 s。
- 对照单模型：Uni-Sign pose 模型侧 P50 277.6 ms、视频端到端 P50 2,690.4 ms（E04）。

## 3. 三问逐条回答

1. **质量是否提高？——否。** 两组 prompt 下 C/D/E 的 BLEU 均低于 A（其中 C−A 在两版均显著为负）；关键对照 D−C、E−D 均不显著；edit 相似度中性。唯一亮点是 v1 的 E−C edit（+0.040），v2 未复现。
2. **是否引入新的关键事实错误？——未验证（缺人评）。** 六槽位盲评（Round-1 评审包已就绪：120 样本 × A/A2/B0、盲序、双评审协议、校验脚本）**等待用户本人回填**；E06 规则槽位冲突只是自动化代理，不能替代人评。抽样可见 LLM 会"改掉正确事实、补全证据外内容"（`report_real_50.md` §5 示例）。
3. **成本是否值得？——不值。** 即使级联把调用压到 28%，也需 ~15k tokens 与 71 s/50 条，换来 BLEU −2.14、edit −0.020；全调 LLM 更是 −6.56 BLEU。对实时/交互语义，P95 5–9.5 s 的额外延迟不可接受（E04 单模型视频端到端 P50 2.69 s）。

## 4. 决策

- **G2 结论：FAIL（融合无质量增益证据）**。按 ADR-P1-008 与 Gate G2 的预先约定：**融合不进主链路；保留可插拔接口与离线评测管线（`experiments/p1/e02/llm_fusion/`），生产默认单模型（Uni-Sign 视频或官方 pose 路径）**。
- 不扩到 1086：在当前证据下扩大样本只会更精确地测量同一个"无增益"结论，白白消耗预算。
- SLRT 的 Gloss 价值仍**未被否定**：B（G2T/SLT）BLOCKED、B0 只是 join 基线；将来若获得 CSL-Daily G2T 权重，应重做 B 与 D vs C。
- Jev/LLM 仲裁（RQ7）**保持 BLOCKED**：无端点级证据支持其纠错能力。

## 5. 重启条件（若未来要再评估融合）

1. 固定且可复现的 LLM 端点 + 模型版本 + prompt 版本（本备忘录已建立管线与记录纪律）；
2. prompt 在**开发集**上系统调优（不是在同一 50 条上反复试错后宣称提升）；
3. 新的独立测试集（未见 signer/环境）且无 GT 泄漏；
4. Round-1 人工评审回填，证明 E/C 类候选在关键事实槽位上**纠对 > 改错**；
5. 明确成本上限（tokens/延迟）并证明质量增益的 CI 不含 0。

## 6. 风险与边界

- 50 条探索批、`retrospective_seen`；不能外推到全量 1086 或新 signer。
- 单端点单模型（deepseek-v4.1-flash）；v1 首轮 max_tokens=256 事故已隔离（73/150 空 completion，未进入对比表）。
- E 组 5/50 失败（长推理截断）已按成功子集报告并披露 n；不影响"未超过 A"的方向。
- 6 槽位人评未做；"关键事实错误"维度的结论仍是**未验证**，不是"通过"。
- 本备忘录不构成对 GLM/其他 LLM 的评测；若要换模型，需重跑同协议并记录。
