基于当前源码，我建议**不要直接引入复杂的数据平台设计**，而是在现有代码基础上演进。当前代码实际上已经具备：

- `collect_data.py`：采集手势序列 → `.npy`
- `train_model.py`：读取 `.npy` → Random Forest → `gesture_model.pkl`
- `desktop_app.py`：摄像头实时识别 + 骨架动画

当前最大的限制是：

1. **数据语义弱**：目前标签直接来自文件名，例如 `A_000.npy`，训练脚本通过文件名解析 label。[train_model]
2. **数据来源单一**：`collect_data.py` 当前固定打开摄像头 `cv2.VideoCapture(0)`。[collect_data]
3. **模型输入格式固定**：当前训练使用 30 帧手部关键点序列，每帧63维。[train_model]
4. **无法区分语言体系**：无法表达 CSL / LIBRAS / ASL 等不同手语体系。


因此建议形成一个 **V2 数据与代码改造方案**。
