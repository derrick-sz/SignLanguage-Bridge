# 中巴手语竞赛：补充数据集核查

核查日期：2026-10-09（Asia/Shanghai）。范围：中国手语 CSL ↔ 巴西手语 Libras；用于竞赛中的有限场景展示和研究评估。本轮只读公开页面、官方说明和小型元数据，未申请访问、下载视频库或重新训练模型。公开数据的场景适配是选型判断，实际词句交集须建立可追溯清单后确认。

## 推荐顺序

| 顺序 | 资源 | 能补什么 | 访问状态与边界 |
|---|---|---|---|
| 1 | 已有 LIBRAS-EQT-UECE RGB + 同源 T 处理版 | 先从现有词句建立受控的日常服务展示；T 可补预处理和原作者分区文件 | RGB 已在项目中；官方 T ZIP 可下载，本地 ZIP 本轮发现无法正常读取，NPY 字段及每条文本覆盖待核验 |
| 2 | CSL-Daily | 中文侧学校、社交、日常服务连续句及整句中文目标 | 研究申请制，需要全职教职签署；竞赛训练和公开展示原始材料应分别检查协议 |
| 3 | UFSC Corpus de Libras | 巴西侧自然交流及校园／学术语料，适合少量精标补充 | 网站资源按地区／项目检索，注册用户可取 EAF；不是已核验的统一完整训练包 |
| 4 | MINDS-Libras | 少量日常孤立词和多签者识别基线 | 作者 Zenodo 开放下载，CC BY 4.0；无连续句翻译标注 |

## 1. LIBRAS-EQT-UECE：先补标注，不把 T 当新增语料

[作者发布版 v4](https://zenodo.org/records/21398895)列出 RGB ZIP（约 9.0 GB）、T ZIP（约 35.6 GB）和 Landmarks ZIP（约 773.6 MB）。[官方 README](https://zenodo.org/records/21398895/files/README.md?download=1)说明：RGB 包同时含孤立手语和连续手语样本；T 包是从这些 RGB 视频提取的处理数据，含 `annotations/train.npy, dev.npy, test.npy`、256×256 帧及提取特征。它不是新增的独立场景数据。

README 的帧目录示例包括葡语句子 `A luz caiu em alguns comodos.`（一些房间停电）。结合项目本地目录可选生活服务／供电咨询任务，但 README **没有公布 NPY 的字段结构**。因此本轮确认的是“有连续视频、有句子名、发布了分区标注”；未确认每条是否含自然葡语目标、独立 gloss 序列、逐词时间边界。不能从 `-T` 名称或 PHOENIX 类似格式推出这些字段齐全。

后续应先验证 ZIP 校验和，再只读抽查分区字段、文本与 RGB 对应关系；同时保留重复、冲突和局部签者编号问题的已有审计结论。项目实盘的视频数与论文／发布概述中的设计数量不能混用。

同轮本地核查发现 `D:/Zenodo/Libras-EQT-UECE-T.zip` 无法读取 ZIP 中央目录，报 BadZipFile，且 `.aria2` 下载状态文件仍在。当前不能把它登记为可用标注包；本轮没有续传或重新下载。

[v4 LICENSE.txt](https://zenodo.org/records/21398895/files/LICENSE.txt?download=1)明确为 CC BY-NC 4.0，允许署名后的非商业分享和改编，需标明改动；README 中泛称的 “Free Use License” 应以这个具体许可证为准。引用和比赛公开展示应固定使用的发布版。

## 2. CSL-Daily：中文侧优先选项

[作者研究组页面](https://ustc-slr.github.io/datasets/2021_csl_daily/)明确提供连续手语视频、gloss 及口语文本翻译。[作者原论文](https://arxiv.org/pdf/2105.12397)表 1、表 2及第 4 节记录：20,654 段视频，10 名签者，2,000 个 gloss；内容涵盖家庭、医疗、学校、银行、购物、社交。适合筛选“校园迎新／互相介绍／询问地点”的中文侧连续句。它不含与同一意思对应的 Libras 视频，也没有已核验的“校园／服务”机器可读分类字段。

官方申请面向大学和研究机构，协议必须由全职工作人员签署，学生本人不能作为签署人；申请流程见官方页面，本轮未申请。[Release Agreement](https://ustc-slr.github.io/datasets/2021_csl_daily/Release-Agreement-CSL-Daily.pdf)限制研究及非商业使用，禁止再分发，并限制公开媒体发布原始图像、视频和标注。**非商业竞赛不等于可以公开发布原数据。** 训练研究可按协议申请；答辩画面／公开演示视频可使用自采且获同意的材料，或向作者确认允许的展示方式。

## 3. UFSC Corpus de Libras：自然交流补充，访问与覆盖逐项核验

[UFSC 官方首页](https://corpuslibras.ufsc.br/?lang=ptbr)说明语料包含引导和自发的 Libras 使用。[项目介绍](https://corpuslibras.ufsc.br/informacoesdoprojeto?lang=ptbr)包括各地 Libras 记录、学术制作、诗歌故事；学术制作列举课程、讲座、会议等。这使其适合查找校园交流和自然表达，而不是仅使用电力服务模板句。

[官方资源说明](https://corpuslibras.ufsc.br/espacointerativo/perguntas/view/7)列出 MP4 视频和 ELAN 转写文件。[权限答复](https://corpuslibras.ufsc.br/espacointerativo/perguntas/view/13)说明自行注册的用户可以取得 EAF；[注册页](https://www.corpuslibras.ufsc.br/registrar)要求研究／教学使用、用 ELAN 并回馈转写和研究结果，以及注明来源和提供者。本轮没有创建账号或实际下载 EAF，不能声称已经获得一组可用训练对。

它是分项目积累的语言学语料库：当前总视频／句子规模、葡语文本覆盖率、统一训练／验证／测试分区、全部 EAF 层级的一致性均**未确认**。应先选 10–20 个相关视频条目检查 EAF 是否存在葡语整句、gloss 及时间信息，再判断能否接入；缺失部分需要新增标注。

[站点使用答复](https://corpuslibras.ufsc.br/espacointerativo/perguntas/view/6)称材料可下载使用，并说明研究应提交伦理审查。按具体项目及机构要求执行；不能仅因网页可浏览就自行概括为统一 CC 许可。竞赛优先用于核对语义和少量标注，不把站点视频直接当成已审核的展示库。

## 4. MINDS-Libras：补日常孤立词，保持任务边界

[UFMG MINDS 实验室](https://minds.eng.ufmg.br/projects.php)链接到作者发布的 [MINDS-Libras Zenodo](https://zenodo.org/records/2667329)。本轮通过[该记录官方 API 元数据](https://zenodo.org/api/records/2667329)确认：20 个孤立词，12 名签者，每词计划录制 5 次；1080p MP4／30 FPS，绿幕受控背景。计划乘积为 1,200 条，但作者明确列有缺失词和额外录制，所以实际完整数量不能直接写为 1,200。

公开词表含 `Aluno`（学生）、`Banheiro`（卫生间）、`Conhecer`（认识）、`Esquina`（街角）、`Maçã`（苹果）等。可补校园／日常词汇并检验跨签者分类，但这 20 词不足以组成校园会话，原库不提供连续句翻译监督。元数据许可为 CC BY 4.0；可按签者 ZIP 分批取得，避免不必要的全量下载。

## 场景分类与中巴语义对齐仍需项目自己补

上述资源提供的主要监督是视频类别、gloss 序列、自然语言文本或语言学转写；本轮未找到经双方审核且直接包含 `scenario_id / intent_id / semantic_id` 的 CSL↔Libras 成对库。这是此次有限候选核查的结论，不是对全球所有资源的穷尽断言。

竞赛中可为选中的少量任务建立一张清单：`scenario_id`（校园／日常服务／文化交流）、`intent_id`（问地点／介绍身份／请求重复）、原始词句及视频 ID、中葡文本、分别对应的 CSL 与 Libras 示例、双方审核状态。场景分类可以先按标签和文本候选筛选；跨语言等义和手语自然表达须人工审核，不能把翻译后词名相同视为语义配对完成。

对于有限场景竞赛，优先复用已有可查的视频和上述申请资源；缺的关键表达，例如“请重复”“没理解”“对／不对”，可设计 20–30 个双方等义短句并单独采录。公开库训练与自采展示集保持来源、签者、词句划分可追溯，才可以说明作品到底验证了已知词句识别、未见签者，还是未见整句翻译。
